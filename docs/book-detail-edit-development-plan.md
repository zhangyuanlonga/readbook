# 书籍详情编辑开发计划

## 使用说明

- [ ] 每完成一个计划项后，直接在本文件中勾选。
- [ ] 执行时严格按本计划推进，不新增本计划之外的功能。
- [ ] 如发现必须调整范围，先更新本文件，再开始实现。

## 范围约束

- [ ] 只开发“书籍详情页编辑”相关能力。
- [ ] 只覆盖在线书与本地图书的“元数据编辑”。
- [ ] 必须同步评估所有消费书籍信息的页面与模块，不得只改详情页本身。
- [ ] 不开发章节内容编辑。
- [ ] 不开发目录逐条编辑。
- [ ] 不开发书源数据回写。
- [ ] 不开发批量编辑。
- [ ] 不顺带扩展其他页面的新功能，除非为了让编辑结果正确显示。

## 目标

- [ ] 在书籍详情页提供统一的“编辑书籍信息”入口。
- [ ] 在线书支持“本地覆盖编辑”。
- [ ] 本地图书支持“本地元数据编辑”。
- [ ] 编辑结果可在详情页正确显示。
- [ ] 编辑结果可在书架、阅读器目录头部等核心展示位置正确同步。

## 联动影响范围

- [x] 先梳理所有消费书籍信息的页面、组件与缓存入口。
- [x] 为每个消费入口标记：
  “一期必须联动” 或 “二期可延后”。
- [x] 禁止遗漏核心展示页，避免出现“详情页已修改，但其他页面仍显示旧数据”。

### 一期必须联动

- [ ] 书籍详情页。
- [ ] 书架页。
- [ ] 阅读器目录头部。
- [ ] 详情页目录头部。
- [ ] 最近阅读 / 继续阅读。

### 二期联动

- [x] 统计页。
- [x] 阅读记录页。
- [x] 发现页。
- [ ] 高级主题相关书籍展示位。
- [x] 本地缓存页。
- [x] 搜索结果页。

## 一期交付范围

### 1. 数据层

- [x] 新增书籍元数据覆盖表，用于保存在线书的本地覆盖信息。
- [x] 定义覆盖数据实体，字段至少包含：
  `title`、`author`、`intro`、`coverPath`、`updatedAt`。
- [x] 设计唯一标识方案：
  在线书使用 `sourceId + detailUrl`；
  本地图书继续使用 `bookId`。
- [x] 提供覆盖数据的增删改查接口。

### 2. 展示解析层

- [x] 新增统一展示解析器，用于合并：
  原始详情数据、本地图书元数据、覆盖数据。
- [x] 明确展示优先级：
  覆盖数据 > 本地图书元数据 > 原始详情数据 > 默认占位。
- [x] 输出统一展示模型，至少包含：
  `displayTitle`、`displayAuthor`、`displayIntro`、`displayCover`。

### 3. 详情页编辑入口

- [x] 将当前详情页“编辑”入口从诊断占位替换为真实编辑入口。
- [x] 保持在线书和本地图书共用同一个编辑入口。
- [x] 根据书籍类型动态展示可编辑项。

### 4. 编辑表单

- [x] 基础信息区支持编辑：
  `书名`、`作者`、`简介`、`封面`。
- [x] 在线书表单显示说明：
  “仅保存在本机，不会修改书源”。
- [x] 本地图书表单显示说明：
  “保存到本地图书资料，影响书架和阅读展示”。
- [x] 本地图书额外支持：
  `编码`、`长章节拆分`。
- [x] 提供按钮：
  `取消`、`保存`、`恢复默认`。

### 5. 保存逻辑

- [x] 在线书保存到覆盖表，不修改书源返回数据。
- [x] 本地图书基础字段直接写回本地图书表。
- [x] 本地图书修改 `编码` 或 `长章节拆分` 时，提供明确处理逻辑：
  立即重建或提示用户重建。
- [x] “恢复默认”逻辑区分在线书和本地图书：
  在线书删除覆盖；
  本地图书恢复本地默认值。

### 6. 联动显示

- [x] 详情页展示改为使用统一展示解析器。
- [x] 书架页接入统一展示解析器。
- [x] 详情页目录头部接入统一展示解析器。
- [x] 阅读器目录头部接入统一展示解析器。
- [ ] 最近阅读 / 继续阅读接入统一展示解析器。

## 二期候选项

- [x] 阅读记录页接入统一展示解析器。
- [x] 缓存页接入统一展示解析器。
- [x] 搜索结果页中已入库图书接入统一展示解析器。
- [x] 统计页接入统一展示解析器。
- [x] 发现页中的书籍展示接入统一展示解析器。
- [ ] 高级主题相关书籍展示位接入统一展示解析器。

## 明确不做

- [ ] 不做章节标题逐条改名。
- [ ] 不做正文内容编辑。
- [ ] 不做在线书源详情字段回写。
- [ ] 不做目录结构编辑。
- [ ] 不做批量元数据编辑。
- [ ] 不做与书籍详情编辑无直接关系的 UI 重构。

## 验收清单

- [x] 在线书可编辑书名、作者、简介、封面。
- [x] 本地图书可编辑书名、作者、简介、封面。
- [x] 本地图书可编辑编码和长章节拆分。
- [x] 保存后详情页立即显示编辑结果。
- [x] 保存后书架页显示同步结果。
- [x] 保存后目录头图和标题显示同步结果。
- [x] 保存后最近阅读 / 继续阅读显示同步结果。
- [ ] 删除覆盖或恢复默认后，展示回退正确。
- [x] 相关页面通过基础分析检查。
