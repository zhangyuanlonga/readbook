# Theme / Color Plan (MD3)

目标：实现类似番茄小说的“阅读页日间/夜间切换 = 全局 UI 主题切换”，并逐步补齐可选配色主题（多套 seed color），让全站风格一致且可持久化。

## 已完成

- [x] 阅读翻页动效：新增“淡入淡出（fade）”选项（点击翻页模式生效）。
- [x] 全局主题联动：阅读页“日间/夜间”切换同步 MaterialApp `ThemeMode`（全局 UI 同步切换）。

## 待办（建议按顺序）

- [x] P0：补充“主题模式”三态：日间/夜间/跟随系统（ThemeMode.system）。
- [x] P0：在“我的”页新增全局主题入口（主题模式切换 + 当前主题状态展示）。
- [x] P0：新增全局 seedColor 选择（至少 4 套：番茄橙、青绿、海蓝、经典紫），并持久化。
- [x] P0：抽离 ThemeData 构建为单点（AppThemeBuilder），统一按钮/卡片/输入框/导航栏/对话框的密度与圆角。
- [ ] P0：清点并替换全局硬编码颜色（若存在）为 `Theme.of(context).colorScheme`。

- [ ] P1：阅读器主题与全局主题的关系策略（推荐提供开关）：
  - 默认：阅读页“日间/夜间”影响全局；阅读背景（纸张/暖色/自定义背景图）仍按阅读设置。
  - 可选：提供“阅读主题独立于全局主题”开关（满足重度用户）。

- [ ] P1：为阅读器补充更多背景色预设（跟随全局色板的 surfaceContainer* 派生），保持暗色下可读性。
- [ ] P1：状态栏/标题栏样式适配（Android/iOS/macOS）：暗色主题时图标前景色正确。

- [ ] P2：Android 12+ 动态取色（可选）：引入 `dynamic_color`，支持系统 Monet 主题，并提供开关。
- [ ] P2：主题切换动效（可选）：全局 themeMode 切换增加轻量淡入（避免突变）。

## 验收标准（关键）

- 阅读页点击“日间/夜间”后：返回书架/书源/我的页面，整体配色同步变化。
- 主题模式/配色在重启 App 后保持。
- 暗色模式下：文字对比度 >= WCAG AA（至少确保常用文本可读）。
