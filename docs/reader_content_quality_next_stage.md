# 正文体验/规则兼容 下一阶段（规划）

目标：把“能读”推进到“读得舒服 + 规则兼容更广 + 故障可定位”。本阶段聚焦正文链路：解析、清洗、排版、分页、遮挡与回归测试。

说明：本计划基于当前项目实现（`ContentTextCleaner` + 阅读分页渲染 + Legado 书源规则兼容）并参考 Legado 规则说明（支持 `##正则##替换内容` 这类替换语法）以及主流小说阅读 App 的通用体验做法。

## P0 必做（影响可用性/正确性）

- [x] R01：修复“正文底部最后一行文字被遮挡”
  - 验收：在不同设备（有/无手势条、有/无刘海）阅读到底部，最后一行可完整显示；弹出/收起底部浮层不影响正文可见区域。
  - 技术点：统一内容区域 bottom padding 计算：`SafeArea.bottom + 底部浮层高度 + 额外缓冲`；分页模式需要把可用高度减去安全区。

- [x] R02：正文清洗增强：换行/段落归一化（兼容更多站点）
  - 处理：`\r\n`、`\r`、HTML `p/div/br/li` 等标签换行语义统一；清洗后段落之间用双换行；避免“一行一句/一行一段”导致的碎片化。
  - 验收：同一章节从不同站点抓取，段落不会出现大量 1-3 个字的碎段；不会把整章合并成一段。

- [x] R03：特殊符号/不可见字符过滤
  - 处理：BOM/零宽字符（如 `\uFEFF`/`\u200B`）、多余 `&nbsp;`、重复空格；保留中文标点、书名号、破折号等可读符号。
  - 验收：正文不出现“看不见但占位”的空白/奇怪断行；复制文本不会带不可见字符。

- [ ] R04：正文内容基本健康校验（fail-fast）
  - 处理：解析结果若包含明显“占位/模板未替换”（如 `{{xxx}}`）、内容过短、只有广告/提示语时，判定为正文失败并提示“正文规则可能不适配”。
  - 验收：用户不会看到一屏广告/占位符当成正文；错误提示可读。

## P1 高收益（提升兼容/体验）

- [ ] R05：广告/水印去除规则升级（可持续迭代）
  - 处理：把现有 `_removeCommonAdPattern` 做成可配置的“规则库”，包含：常见提示语、域名、跳转、章节未完、请收藏、手机访问等。
  - 验收：测试样例中广告行明显减少且不误杀正文。

- [ ] R06：段落/缩进策略更贴合中文小说
  - 处理：识别正文中已有前导全角空格（`\u3000`）/多空格缩进，统一折算到阅读设置 `首行缩进`，避免“双重缩进”。
  - 验收：同一章在不同源下缩进一致；不会出现“缩进越来越大”。

- [ ] R07：HTML 转纯文增强
  - 处理：对 `img`/`a`/`span` 等标签更谨慎：保留必要文本，忽略脚本样式；可选保留图片占位（后续做图文混排可用）。
  - 验收：带大量 `p`/`span` 包裹的正文不丢字；不残留标签。

- [ ] R08：分页一致性与“衔接不上”问题专项
  - 处理：分页算法要保证 page[i] + page[i+1] 文本连续无缺字/重复；对中文断句/标点做“行首标点挤压”的最小修复（可选）。
  - 验收：连续翻页时，上一页末尾和下一页开头能自然衔接，不丢字不重复。

- [ ] R09：错误定位增强（便于用户反馈/你调试）
  - 处理：正文失败提示里附带：sourceName、chapterUrl、解析阶段（请求/解析/清洗/分页）、命中的清洗规则（如有）。
  - 验收：用户截图即可复现定位问题。

## P2 可选（有空再做）

- [ ] R10：正文“章节内搜索”结果高亮优化（不影响阅读性能）
- [ ] R11：正文“错别字/重复段”简单检测（低优先级）
- [ ] R12：清洗规则的用户开关/自定义（重度用户向）

## 建议的实现拆分（便于逐步验证）

1. 内容区布局/遮挡（R01）先做，因为这是纯 UI 可见 bug。
2. `ContentTextCleaner` 拆成流水线：`htmlNormalize -> htmlToText -> normalizeWhitespace -> removeAds -> normalizeParagraphs -> finalTrim`，每一步加单测。
3. 用你提供的 `read.json / test1.json / test_read.json` 选 5-10 个典型源做回归 fixture：覆盖 HTML/JSON、换行风格不同、带广告等。

## 回归用例（建议）

- 样例 A：`<p>` + `<br>` 混用，内容包含 `&nbsp;`。
- 样例 B：每行一个 `<br>`，但其实应该合并成段落。
- 样例 C：正文夹杂“最新网址/请收藏/本章未完”等。
- 样例 D：正文含零宽字符/奇怪空白。
- 样例 E：正文解析为空/只有模板占位符 `{{xxx}}`。
