# 阅读器多模态手动回归清单

更新时间：2026-05-25

## 1. 文本模式

- [ ] 打开 TXT / 流式 EPUB，默认进入 `text`
- [ ] 分页阅读下可正常翻页、恢复页码
- [ ] 滚动阅读下可正常恢复滚动位置
- [ ] 自动阅读可开启、暂停、继续、退出
- [ ] 文字选择、灵感、划线、笔记不回退
- [ ] 正文图片点击 / 长按进入全屏预览
- [ ] 图片预览关闭后能继续阅读

## 2. PDF / Hybrid 模式

- [ ] 打开文本层 PDF，进入 `hybrid`
- [ ] 打开扫描版 / 无文本层 PDF，仍可按页阅读
- [ ] 双指缩放、单指平移正常
- [ ] 退出阅读器后再次进入，恢复到正确页
- [ ] 九宫格点击中的自动阅读动作会提示不支持
- [ ] 设置面板中不会错误展示自动阅读入口

## 3. 固定版式 EPUB

- [ ] 命中 fixed-layout 信号的 EPUB 进入 `hybrid`
- [ ] 普通流式 EPUB 仍进入 `text`
- [ ] fixed-layout 章节不会误触发正文自动阅读
- [ ] 页码恢复逻辑可用

## 4. 绘本 / 杂志

- [ ] 单页纯图片章节进入 `picture-book` 路径
- [ ] 图片页进度保存与恢复正常
- [ ] 不会误走漫画连续滚动入口
- [ ] 缩放和页码恢复正常

## 5. 漫画模式

- [ ] 连续滚动漫画不回退
- [ ] 分页漫画不回退
- [ ] 横向模式不回退
- [ ] 缩放时不会误触正文点击分区
- [ ] 音量键翻页在分页漫画下行为正常

## 6. 听书模式

- [ ] 听书章节进入 `audio`
- [ ] 播放 / 暂停 / 重播正常
- [ ] 倍速切换正常
- [ ] 退出阅读器后再次进入，恢复到上次播放时间
- [ ] 自动阅读入口被禁用或提示不支持
- [ ] 设置面板展示为听书相关分组，不误导到自动阅读

## 7. 跨模式交互

- [ ] 目录入口在 text / hybrid / comic 下可正常打开
- [ ] 长按正文在 text 下不回退
- [ ] 长按图片在 text 下进入图片预览
- [ ] 长按漫画页不误触正文选择
- [ ] 夜间模式切换在 text / hybrid / comic / audio 下不会崩溃
- [ ] 音量键翻页在不支持模式下不会出现异常行为
