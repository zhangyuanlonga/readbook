# 脚本源文档索引

更新时间：2026-04-01

当前 `flutterreadbook` 运行时只支持脚本源。

这组文档用于说明脚本源在 `flutterreadbook` 中的现行写法、规范、能力边界和实现约束。

当前约定：

- App 运行时只加载脚本源，不再导入或执行旧规则 JSON。
- 作者侧文档只以脚本源写法为准。

建议阅读顺序：先看作者手册，再看规范，再看运行时 API，最后按需阅读架构文档。

## 主线文档

1. [官方书源编写手册](./official-source-author-guide.md)
   书源作者的主入口。包含模板、流程、标准对象、方法职责和完整 `ctx.*` API。
2. [书源规范 v1](./source-spec-v1.md)
   规范性文档。只定义书源文件结构、标准对象和兼容约定。
3. [宿主运行时 API](./runtime-ctx-api.md)
   边界说明文档。只说明当前运行时到底开放了什么，以及哪些能力不要误解。
4. [总体架构](./architecture.md)
   用于说明当前脚本源运行时在产品中的角色和核心模块。

## 开发文档

- [第二阶段：Browser / Cookie / Cache 设计说明](./stage-two-browser-sources.md)
  只在你需要理解浏览器能力的设计取舍时阅读，不是入门必读。

## 模板

- [标准完整模板](../templates/source_template_v1.js)
  当前唯一保留的官方模板，所有场景都从这里裁剪扩展，避免多模板造成认知分叉。

联动维护约定：

- 任何“字段规范”改动，必须同步更新官方模板 `source_template_v1.js`

一句话分工：

- 主手册负责“怎么写”
- 规范文档负责“什么算合规”
- 运行时文档负责“当前实现到哪里”
- 架构文档负责“模块怎么协作”
