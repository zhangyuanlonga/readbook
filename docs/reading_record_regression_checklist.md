# 阅读记录回归测试清单

更新时间：2026-03-21

本文用于阅读记录功能的手动回归与发布前检查。

## 1. 环境准备

- [ ] 使用最新代码构建 App
- [ ] 准备一本文字正文书
- [ ] 准备一部漫画书
- [ ] 准备至少两条同标题记录样本：
  - [ ] 一条作者一致或作者缺失
  - [ ] 一条作者明显不同

## 2. 基础链路

### 2.1 新装基线

- [ ] 清空 App 数据或新装
- [ ] 打开阅读记录页
- [ ] 确认页面正常展示，无崩溃、无空白异常
- [ ] 确认顶部显示当前阅读记录状态

### 2.2 阅读写入

- [ ] 开关开启时阅读文本书超过 10 秒
- [ ] 返回阅读记录页
- [ ] 确认最近阅读新增
- [ ] 确认按天汇总新增
- [ ] 确认时间线新增
- [ ] 确认热力图有对应日期数据
- [ ] 确认摘要卡统计同步变化

### 2.3 开关关闭

- [ ] 在系统设置关闭阅读记录
- [ ] 停留或返回阅读记录页
- [ ] 确认顶部状态实时刷新为关闭
- [ ] 再次阅读超过 10 秒
- [ ] 确认不新增记录
- [ ] 确认旧记录仍保留

## 3. 三视图与过滤

### 3.1 三视图切换

- [ ] 最近阅读正常展示
- [ ] 按天汇总正常展示
- [ ] 时间线正常展示

### 3.2 热力图过滤

- [ ] 点击某个有数据日期
- [ ] 三个视图都只显示该日期相关内容
- [ ] 摘要卡切换为当日概览
- [ ] 点击清除后恢复全量

### 3.3 搜索叠加过滤

- [ ] 输入书名关键字
- [ ] 确认搜索结果正确
- [ ] 在搜索状态下再点热力图日期
- [ ] 确认搜索与日期过滤可叠加

## 4. 删除与撤销

### 4.1 最近阅读

- [ ] 删除一整本阅读记录
- [ ] 确认列表立即刷新
- [ ] 点击 Snackbar 的撤销
- [ ] 确认整书记录恢复

### 4.2 按天汇总

- [ ] 删除某本书某天记录
- [ ] 确认当天分组刷新
- [ ] 点击撤销
- [ ] 确认当天记录恢复

### 4.3 时间线

- [ ] 删除单条会话
- [ ] 确认时间线、摘要、热力图同步刷新
- [ ] 点击撤销
- [ ] 确认会话与聚合恢复

### 4.4 删除确认

- [ ] 首次删除会弹确认框
- [ ] 勾选“本次不再确认”后，同页后续删除不再弹确认
- [ ] 重新进入页面后恢复确认弹窗

## 5. 合并安全

### 5.1 候选排序与过滤

- [ ] 打开合并弹窗
- [ ] 作者一致候选排前
- [ ] 作者缺失候选显示“需确认”
- [ ] 作者明显不同候选不进入列表

### 5.2 合并结果

- [ ] 执行低风险合并
- [ ] 确认最近阅读、按天汇总、时间线统计一致
- [ ] 确认目标记录章节定位仍可用

### 5.3 风险确认

- [ ] 选择“需确认”候选时出现二次确认
- [ ] 取消后不执行合并
- [ ] 确认继续后正常合并

## 6. 字数统计口径

### 6.1 文本正文

- [ ] 向前连续阅读，确认字数增加
- [ ] 回退阅读一段后退出，确认不会把回退部分当新增字数
- [ ] 来回快速拖动后退出，确认字数没有明显异常放大

### 6.2 分页模式

- [ ] 切换到分页模式
- [ ] 连续前进数页后退出
- [ ] 确认字数正常增加
- [ ] 翻回前页再退出
- [ ] 确认不会把回翻页数再记成新增字数

### 6.3 跳章

- [ ] 阅读当前章一段内容后直接切到下一章
- [ ] 确认上一章会话已提交
- [ ] 确认下一章从新会话开始

### 6.4 漫画章节

- [ ] 阅读漫画章节超过 10 秒
- [ ] 确认时长、会话、热力图正常记录
- [ ] 确认主“阅读字数”不因漫画章节增加

## 7. 热力图表达

- [ ] 验证近 3 个月 / 近 6 个月 / 近 1 年 / 全部切换正常
- [ ] 确认范围切换后日期区间文案同步变化
- [ ] 确认月份标签显示合理

## 8. 发布前结论

- [ ] 基础链路通过
- [ ] 三视图联动通过
- [ ] 删除与撤销通过
- [ ] 合并安全通过
- [ ] 字数口径 spot check 通过
- [ ] 热力图表达通过
- [ ] 可进入发布或下一阶段迭代
