# 存储与数据生命周期完整指南

更新时间：2026-06-10  
用途：明确定义用户数据存储位置、生命周期、覆盖安装/卸载行为

## 当前落地状态（2026-06-10）

- 启动首帧后延迟 3 秒会在后台依次执行：
  - 废弃 SharedPreferences key 一次性清理
  - `AppCacheGovernanceService.enforceBudgets()` 缓存预算治理
  - 每 7 天一次的数据库存储维护
- 启动前会额外执行：
  - fresh install / 重装场景下的 auth 凭证自恢复清理
  - `app.data_version` 迁移与关键配置修复
  - 数据库完整性 quick check；损坏时备份并重建
- 当前已纳入自动清理的废弃 key 首批清单：`reader.local.txt.chapterRules`
- 当前数据库维护会自动清理：
  - 已不存在本地图书对应的本地阅读进度
  - 已不存在本地图书对应的本地阅读记录 / 会话 / 阅读状态
  - 已不存在本地图书对应的 TOC 快照和本地元数据覆盖
  - 超过 90 天未更新的搜索源命中统计
- 当前删除本地图书时，会同步清理其关联书签、阅读进度、阅读记录、阅读状态、TOC 快照和本地元数据覆盖
- 当前“系统 → 存储管理”页已提供基础统计、清理所有缓存和清理孤立数据入口
- 当前“系统 → 重置应用数据”会清空 SharedPreferences、登录状态、数据库和缓存，并保留本地图书与托管用户资源
- 数据库损坏提示交互、schema 迁移失败回滚和更细的存储分类统计仍待继续推进，计划以 `storage_governance_improvement_plan.md` 为准

## 1. 核心问题回答

### 1.1 用户本地存储什么？

#### 用户资产（不可丢失）
1. **本地图书文件**
   - 存储位置：`Support/local_books/`
   - 包含：EPUB、TXT、PDF 源文件
   - 生命周期：用户主动删除才会删除

2. **自定义封面**
   - 存储位置：`Support/shuxiang_reading_next/custom_covers/`
   - 包含：用户上传的书籍封面图片
   - 生命周期：绑定书籍，书籍删除时一起删除

3. **阅读器自定义背景图**
   - 存储位置：`Documents/reader_backgrounds/`
   - 包含：用户上传的阅读器背景图
   - 生命周期：用户在设置中主动删除

4. **应用背景图**
   - 存储位置：`Documents/backgrounds/`
   - 包含：应用全局背景图片
   - 生命周期：用户在设置中主动删除

5. **高级主题资源**
   - 存储位置：`Documents/advanced_themes/<themeId>/`
   - 包含：主题壁纸、图标、字体等完整资源包
   - 生命周期：用户主动删除主题

6. **封面图集、启动图集**
   - 存储位置：`Documents/cover_galleries/`, `Documents/launch_image_galleries/`
   - 包含：用户创建的图集图片
   - 生命周期：用户主动删除图集

7. **底部导航图标**
   - 存储位置：`Support/bottom_nav_icon_galleries/`
   - 包含：自定义导航图标
   - 生命周期：用户主动删除

8. **阅读器字体**
   - 存储位置：`Support/reader_fonts/`
   - 包含：用户导入的字体文件
   - 生命周期：用户主动删除

9. **用户头像**
   - 存储位置：`Documents/profile_avatars/`
   - 包含：用户设置的头像图片
   - 生命周期：用户更换头像时旧头像删除

#### 业务主数据（不可丢失）
1. **阅读进度**
   - 存储位置：Drift 数据库 `reading_progresses` 表
   - 包含：每本书的阅读位置、进度百分比
   - 生命周期：用户主动删除书籍或清除进度

2. **书架数据**
   - 存储位置：SharedPreferences `bookshelf.books`（待迁移到数据库）
   - 包含：书籍列表、分组、排序
   - 生命周期：用户主动删除书籍

3. **书签**
   - 存储位置：Drift 数据库 `bookmarks` 表
   - 包含：用户标记的书签位置和备注
   - 生命周期：用户主动删除书签

4. **本地图书索引**
   - 存储位置：Drift 数据库 `local_books`, `local_chapters` 表
   - 包含：本地书籍元信息、章节目录
   - 生命周期：绑定本地图书文件，文件删除时一起删除

5. **私人书源**
   - 存储位置：服务器（通过 API）
   - 包含：用户自己创建的书源配置
   - 生命周期：用户主动删除书源

6. **搜索源命中统计**
   - 存储位置：Drift 数据库
   - 包含：各个搜索源的使用频率统计
   - 生命周期：用于优化搜索排序，可清除

#### 轻量配置和偏好（可丢失，影响体验）

1. **阅读器设置**
   - 存储位置：SharedPreferences `reader.settings.*`
   - 包含：字体大小、行距、背景色、翻页方式等
   - 生命周期：持久保留，除非用户重置设置

2. **应用外观偏好**
   - 存储位置：SharedPreferences `app.*`
   - 包含：主题选择、语言、启动图等
   - 生命周期：持久保留

3. **搜索历史**
   - 存储位置：SharedPreferences `search.history`
   - 包含：最近搜索关键词列表
   - 生命周期：可清除，不影响核心功能

4. **最近使用颜色**
   - 存储位置：SharedPreferences `reader.recentBodyTextColors`
   - 包含：阅读器颜色选择器的最近颜色
   - 生命周期：可清除

5. **当前激活主题快照**
   - 存储位置：SharedPreferences `app.activeAdvancedThemeSnapshot`
   - 包含：启动预热用的轻量主题外观信息
   - 生命周期：主题切换时更新

#### 敏感信息（加密存储）

1. **登录凭证**
   - 存储位置：`flutter_secure_storage`
   - 包含：access_token, refresh_token, 过期时间
   - 生命周期：登出时清除

2. **用户基本信息（非敏感部分）**
   - 存储位置：SharedPreferences `auth.*`
   - 包含：user_id, username, display_name（仅用于展示）
   - 生命周期：登出时清除

#### 可重建缓存（可随时删除）

1. **章节内容缓存**
   - 存储位置：Drift 数据库 `chapter_caches` 表
   - 预算：最多 2000 条，180天过期
   - 包含：在线书籍的章节正文
   - 清除影响：重新加载较慢，不影响正确性

2. **分页布局缓存**
   - 存储位置：缓存目录（具体路径待确认）
   - 预算：最多 1000 条，90天过期
   - 包含：阅读器排版计算结果
   - 清除影响：重新打开需要重排版

3. **封面磁盘缓存**
   - 存储位置：缓存目录
   - 预算：最多 500 张，30天过期，50MB
   - 包含：书籍封面图片
   - 清除影响：重新下载封面

4. **临时工作目录**
   - 存储位置：系统临时目录
   - 包含：导入导出过程中的临时文件、诊断日志导出
   - 清除影响：无，系统会自动清理

### 1.2 覆盖安装时会清除什么？

**Android / iOS / Desktop 原生覆盖安装行为：**

#### ✅ 保留的数据
- ✓ Documents 目录：所有用户资产（背景图、主题、图集、头像）
- ✓ Support 目录：本地图书、自定义封面、字体、图标
- ✓ SharedPreferences：所有用户设置和偏好
- ✓ Drift 数据库：阅读进度、书签、书架数据
- ✓ flutter_secure_storage：登录凭证

#### ❌ 可能清除的数据（取决于系统）
- 缓存目录（Caches）：章节缓存、分页缓存、封面缓存
- 系统临时目录：临时工作文件

**结论：覆盖安装不会丢失任何用户资产和核心数据，只会清除可重建的缓存。**

### 1.3 卸载 APP 时删除什么？

**Android / iOS / Desktop 卸载行为：**

#### ❌ 完全删除
- Documents 目录：**所有用户资产会丢失**
- Support 目录：**本地图书、配置全部丢失**
- SharedPreferences：**所有设置丢失**
- Drift 数据库：**阅读进度、书签全部丢失**
- flutter_secure_storage：**登录凭证丢失**
- 缓存目录：缓存删除
- 临时目录：临时文件删除

**结论：卸载 APP 会删除所有本地数据，包括用户资产。**

**未来改进方向：**
- 提供"导出用户数据"功能
- 支持 WebDAV / 云端同步备份
- 卸载前提示用户备份重要数据

### 1.4 重新安装时如何处理本地旧数据？

**情况1：卸载后重装**
- 结果：所有数据已被删除，应用从零开始
- 用户体验：需要重新登录、重新导入图书、重新配置设置

**情况2：覆盖安装（升级）**
- 结果：保留所有用户数据，只升级代码
- 数据迁移：应用启动时自动检测数据库版本，执行必要的迁移
- 用户体验：无缝升级，数据完整保留

**情况3：同设备多账号切换**
- 当前行为：数据混用（所有账号共享本地数据）
- 问题：账号A的阅读进度可能被账号B看到
- 未来改进：按账号隔离本地数据，或提供"切换账号时清除本地数据"选项

## 3. 数据清理策略

### 3.1 应用内清理入口

#### ✅ 允许的清理操作

1. **清理缓存**
   - 入口：设置 → 存储管理 → 清理缓存
   - 清理内容：章节缓存、分页缓存、封面缓存
   - 影响：下次使用时重新加载，不影响正确性

2. **删除单个书籍**
   - 入口：书架 → 长按书籍 → 删除
   - 清理内容：书架记录、阅读进度、书签、本地图书文件（如果是本地书）
   - 影响：该书相关的所有数据被删除

3. **删除主题/图集**
   - 入口：对应资源管理页面
   - 清理内容：主题资源目录、图集图片
   - 影响：无法再使用该主题/图集

4. **清除搜索历史**
   - 入口：搜索页 → 清除历史
   - 清理内容：搜索关键词列表
   - 影响：不再显示历史搜索

5. **登出**
   - 入口：我的 → 登出
   - 清理内容：登录凭证、用户基本信息
   - 影响：需要重新登录，本地数据保留

#### ❌ 禁止的清理操作

1. **"清理全部本地数据"** - 风险太高，容易误操作
2. **启动期自动清理用户资产** - 未经用户同意
3. **模糊目录匹配删除** - 可能误删

### 3.2 缓存预算策略

| 缓存类型 | 最大条目 | 最大体积 | 过期时间 | 清理策略 |
|---------|---------|---------|---------|---------|
| 章节缓存 | 2000条 | 无限制 | 180天 | LRU + 过期 |
| 分页布局 | 1000条 | 无限制 | 90天 | LRU + 过期 |
| 封面图片 | 500张 | 50MB | 30天 | LRU + 过期 |

**自动清理时机：**
- 应用启动时检查并执行预算压缩
- 缓存写入时超过预算自动清理最旧的
- 用户主动点击"清理缓存"

### 3.3 数据迁移策略

**启动时数据库版本检查：**

```dart
// 数据库从 v1 升级到 v2 的迁移
@override
MigrationStrategy get migration => MigrationStrategy(
  onCreate: (Migrator m) async {
    await m.createAll();
  },
  onUpgrade: (Migrator m, int from, int to) async {
    if (from < 2) {
      // 添加新列
      await m.addColumn(readingProgresses, readingProgresses.lastReadAt);
    }
    if (from < 3) {
      // 数据迁移
      await customStatement('UPDATE books SET ...');
    }
  },
);
```

**SharedPreferences 迁移策略：**

- 新版本写新 key，保留旧 key 兼容读取
- 启动时检测旧 key，迁移到新结构后删除旧 key
- 避免硬删除，先标记废弃，观察几个版本后再删除

## 4. 平台差异处理

### 4.1 Android

**特点：**
- 支持 scoped storage（分区存储）
- 应用卸载时完全删除数据
- 覆盖安装保留所有数据

**注意事项：**
- Android 10+ 需要适配 scoped storage
- 外部存储访问需要权限
- backup 规则配置影响 Google Drive 自动备份

### 4.2 iOS

**特点：**
- 沙盒隔离严格
- iCloud 可以自动备份 Documents 和 Support
- 卸载完全删除

**注意事项：**
- 缓存目录可能被系统自动清理
- Documents 目录会同步到 iCloud（如果用户开启）
- 需要在 Info.plist 配置文件权限

### 4.3 Web

**特点：**
- 使用 IndexedDB 代替 Drift 数据库
- 浏览器清除数据时全部删除
- 无真实文件系统

**注意事项：**
- 本地图书能力受限（只能通过上传）
- 存储配额有限制
- 用户清除浏览器数据时丢失所有内容
- 需要提示用户定期备份

### 4.4 Desktop (macOS/Windows/Linux)

**特点：**
- 完整文件系统访问
- 卸载不一定删除配置（取决于卸载方式）
- 支持用户主动选择文件路径

**注意事项：**
- 用户可能手动删除应用目录
- 需要处理文件路径权限问题
- 支持拖拽导入

## 5. 最佳实践建议

### 5.1 开发规范

1. **不要在 SharedPreferences 存储大 JSON**
   - 违规：`prefs.setString('books', jsonEncode(largeList))`
   - 正确：使用 Drift 数据库

2. **不要硬编码文件路径**
   - 违规：`/data/user/0/com.app/files/image.jpg`
   - 正确：使用 `ManagedAssetStore` 存储相对路径

3. **不要把用户资产放缓存目录**
   - 违规：`getTemporaryDirectory()/user_book.epub`
   - 正确：`getApplicationSupportDirectory()/local_books/`

4. **不要启动时自动删除用户数据**
   - 违规：启动时清理所有旧主题
   - 正确：只清理过期缓存，用户资产需要用户主动删除

5. **数据库迁移要向前兼容**
   - 违规：直接删除旧表
   - 正确：保留旧数据兼容读取，新数据写新结构

### 5.2 用户体验建议

1. **提供数据导出功能**
   - 导出阅读进度、书签到 JSON
   - 导出主题包、图集
   - 支持 WebDAV 同步

2. **清理操作要明确提示**
   - "清理缓存"清楚说明会删除什么
   - "删除书籍"提示是否删除本地文件
   - 危险操作需要二次确认

3. **首次安装引导**
   - 说明数据存储位置
   - 提示开启自动备份
   - 说明卸载会删除数据

4. **存储空间管理**
   - 显示各类数据占用空间
   - 提供分类清理入口
   - 预警存储空间不足

## 6. 故障排查

### 6.1 常见问题

**问题1：覆盖安装后数据丢失**
- 原因：可能把数据存在了临时目录
- 排查：检查文件路径是否使用正确的目录
- 解决：迁移到 Support 或 Documents 目录

**问题2：卸载后数据仍然存在**
- 原因：部分平台/卸载方式可能保留配置
- 排查：检查系统行为
- 解决：这是正常的平台差异

**问题3：缓存占用过大**
- 原因：缓存预算未正确执行
- 排查：检查 `AppCacheGovernanceService`
- 解决：调整预算参数或手动清理

**问题4：数据库迁移失败**
- 原因：迁移逻辑错误或数据损坏
- 排查：查看日志中的迁移错误
- 解决：提供回退方案，保留旧版本兼容

### 6.2 诊断工具

**应用内诊断：**

- 设置 → 关于 → 存储信息
  - 显示各目录实际路径
  - 显示数据库版本
  - 显示缓存占用

- 设置 → 开发者选项 → 导出诊断日志
  - 包含存储状态快照
  - 不包含用户敏感数据

### 7.3 长期改进（6个月以上）

1. ⏳ 增量备份机制

## 8. 总结

### 核心原则

1. **用户资产不可丢失** - Documents 和 Support 目录
2. **缓存可随时删除** - Caches 目录
3. **临时文件系统自动清理** - Temporary 目录
4. **敏感信息加密存储** - SecureStorage
5. **轻量配置用 SharedPreferences** - 不存大 JSON
6. **业务数据用数据库** - Drift 表结构化存储

### 关键行为

- ✅ **覆盖安装**：保留所有数据，只升级代码
- ❌ **卸载应用**：删除所有数据，包括用户资产
- ✅ **清理缓存**：只删除可重建缓存
- ❌ **清理全部**：不提供此入口，风险太高
