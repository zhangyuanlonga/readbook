# 应用组件统一与高级主题覆盖阶段计划（2026-06-21）

## 目标

把非阅读器页面中仍然散落的硬编码样式、本地圆角、本地透明度、重复卡片/弹窗/输入/按钮写法，逐步收敛到现有 UI Kit 与高级主题 token 下，最终做到：

- 高级主题可以统一影响按钮、卡片、输入框、弹窗、底部面板、导航、选择控件和常见资源卡片。
- 页面开发优先复用 `AppButton`、`AppSurface`、`AppTextField`、`AdaptiveActionSurface`、`AdaptiveRouteTopBar`、`AppProgressIndicator`、`AppFeedback` 等组件。
- 新增 UI 通过 `dart tool/check_ui_component_governance.dart --strict-new`，不再扩大历史硬编码债务。
- 阅读器保持后置，避免把核心阅读体验和普通 App 页面治理混在一起。

## 排序原则

1. 优先做低风险、高收益、影响面明确的统一。
2. 优先非阅读器页面。
3. 优先能被高级主题立刻覆盖的组件：按钮、卡片、输入框、弹窗、资源卡片。
4. 最后处理阅读器和大页面拆分，因为它们涉及阅读体验、性能、手势、层级和业务状态。
