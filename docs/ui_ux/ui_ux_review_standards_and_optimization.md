# UI/UX 全面审查标准与优化方向

创建时间：2026-06-10  
角色：产品经理 + UI 设计师  
用途：**可执行的审查清单 + 优化方向**，用于全页面审查

---

## 📋 审查清单（每个页面必查）

### 一、视觉一致性审查

#### 1.1 圆角规范 ✓/✗

- [ ] 卡片圆角是否为 20dp
- [ ] 按钮圆角是否为 14dp 或 stadium
- [ ] 输入框圆角是否为 14dp
- [ ] 弹窗圆角是否为 16dp
- [ ] 底部弹层顶部圆角是否为 20dp

**不合格示例：**
- 卡片用了 16dp、12dp 等其他值
- 同一页面多种圆角混用

---

#### 1.2 间距规范 ✓/✗

- [ ] 页面内边距是否为 16dp
- [ ] 卡片内边距是否为 12dp
- [ ] 卡片间距是否为 8-12dp
- [ ] 组件间距是否为 8/12/16dp（不要出现 10、15、20 等随意值）
- [ ] 是否有过大间距（>32dp）或过小间距（<4dp）

**不合格示例：**
- 内边距用了 10dp、15dp、18dp 等随意值
- 同一页面间距不统一

---

#### 1.3 颜色使用 ✓/✗

- [ ] 是否使用 Theme.of(context).colorScheme 而不是硬编码颜色
- [ ] 是否避免直接使用 Colors.red、Colors.blue
- [ ] 文字颜色是否使用 onSurface / onSurfaceVariant
- [ ] 背景颜色是否使用 surface / surfaceContainerLow
- [ ] 边框颜色是否使用 outlineVariant

**不合格示例：**
- `color: Color(0xFF123456)` 硬编码
- `color: Colors.blue` 直接用 Material 颜色

---

#### 1.4 字体规范 ✓/✗

- [ ] 标题是否使用 titleLarge / titleMedium
- [ ] 正文是否使用 bodyLarge / bodyMedium
- [ ] 标签/辅助文字是否使用 bodySmall / labelMedium
- [ ] 是否避免自定义 fontSize（如 15、17、19 等随意值）

**不合格示例：**
- `fontSize: 15` 自定义大小
- 没有使用 TextTheme

---

### 二、交互体验审查

#### 2.1 点击反馈 ✓/✗

- [ ] 所有可点击元素是否有视觉反馈
- [ ] 按钮是否有按下状态（颜色变化或缩放）
- [ ] 列表项是否有水波纹效果（InkWell）
- [ ] 桌面端是否有 hover 状态
- [ ] 触摸目标是否≥44x44dp（移动端）

**不合格示例：**
- 用 GestureDetector 没有视觉反馈
- 按钮点击没有任何变化

---

#### 2.2 加载状态 ✓/✗

- [ ] 首屏加载是否有加载指示器
- [ ] 列表加载更多是否有底部指示器
- [ ] 下拉刷新是否有刷新指示器
- [ ] 按钮操作中是否禁用并显示 loading
- [ ] 加载失败是否有错误提示和重试按钮

**不合格示例：**
- 点击按钮无响应，不知道是否在加载
- 网络错误直接卡死

---

#### 2.3 空状态 ✓/✗

- [ ] 列表为空是否有空状态提示
- [ ] 空状态是否包含：图标 + 文字 + 行动建议
- [ ] 空状态文案是否友好（不要"无数据"）
- [ ] 空状态是否提供下一步操作（如"添加第一本书"）

**不合格示例：**
- 空列表只显示"暂无数据"
- 没有任何行动建议

---

#### 2.4 错误状态 ✓/✗

- [ ] 网络错误是否有提示
- [ ] 错误提示是否友好（不要技术术语）
- [ ] 是否提供重试按钮
- [ ] 是否区分不同错误类型（网络/服务器/权限）

**不合格示例：**
- 显示 "Error: 500 Internal Server Error"
- 错误后无法恢复，只能退出

---

#### 2.5 确认操作 ✓/✗

- [ ] 删除操作是否有确认对话框
- [ ] 危险操作是否用红色标识
- [ ] 确认对话框是否说明后果（"删除后无法恢复"）
- [ ] 按钮顺序是否正确（左取消，右确定）

**不合格示例：**
- 删除直接执行，没有确认
- 确认按钮在左边，取消在右边

---

### 三、动画流畅性审查

#### 3.1 页面过渡 ✓/✗

- [ ] 页面进入是否有过渡动画
- [ ] 页面返回是否流畅
- [ ] 过渡时长是否合理（200-400ms）
- [ ] 是否使用合适的曲线（easeInOut）

**不合格示例：**
- 页面直接跳转，无过渡
- 过渡时间过长（>600ms）

---

#### 3.2 列表动画 ✓/✗

- [ ] 列表项是否有进入动画（可选）
- [ ] 删除项是否有退出动画
- [ ] 新增项是否有进入动画
- [ ] 动画是否流畅（60fps）

**不合格示例：**
- 删除项直接消失
- 动画卡顿

---

#### 3.3 微交互 ✓/✗

- [ ] 按钮点击是否有反馈动画
- [ ] 开关切换是否有动画
- [ ] 展开/收起是否有动画
- [ ] 数值变化是否有过渡（可选）

**不合格示例：**
- 所有操作都是瞬间完成，没有过渡

---

### 四、响应式适配审查

#### 4.1 移动端适配 ✓/✗

- [ ] 底部导航栏是否正常
- [ ] 安全区是否处理（刘海屏、底部横条）
- [ ] 横屏是否适配
- [ ] 键盘弹起是否正常

**不合格示例：**
- 刘海屏被遮挡
- 键盘遮挡输入框

---

#### 4.2 平板适配 ✓/✗

- [ ] 大屏幕是否利用空间（不要只是放大）
- [ ] 是否使用双栏布局（可选）
- [ ] 内容宽度是否有最大限制（避免过宽）

**不合格示例：**
- 平板上内容拉得很宽，难以阅读

---

#### 4.3 桌面端适配 ✓/✗

- [ ] 侧边栏导航是否正常
- [ ] 鼠标 hover 是否有反馈
- [ ] 键盘快捷键是否可用（可选）
- [ ] 右键菜单是否可用（可选）
- [ ] 窗口缩放是否适配

**不合格示例：**
- 移动端 UI 直接放到桌面
- 没有 hover 状态

---

### 五、文案与可读性审查

#### 5.1 文案质量 ✓/✗

- [ ] 是否避免技术术语（"Token过期"改为"登录已过期"）
- [ ] 是否友好（"暂无数据"改为"还没有添加书籍"）
- [ ] 是否提供行动建议（"点击+添加第一本书"）
- [ ] 错误提示是否说人话

**不合格示例：**
- "Error: Unauthorized 401"
- "无数据"

---

#### 5.2 可读性 ✓/✗

- [ ] 正文字号是否≥14sp
- [ ] 对比度是否足够（不要用浅灰色文字）
- [ ] 行距是否合理
- [ ] 段落间距是否足够

**不合格示例：**
- 12sp 小字
- 浅灰色文字看不清

## 🎯 优化方向（按优先级）

### P0 - 影响核心体验（必须做）

#### 方向1：统一视觉规范

**问题：** 圆角、间距、颜色使用不统一

**优化：**
1. 创建 Design Token 文件
2. 全页面统一圆角（卡片 20dp）
3. 全页面统一间距（页面 16dp、卡片内 12dp）
4. 移除所有硬编码颜色

**验收：**
- 所有页面通过"视觉一致性审查"

**执行：** 2-3周

---

#### 方向2：补充缺失状态

**问题：** 空状态、错误状态、加载状态不完善

**优化：**
1. 创建统一的 AppEmptyState 组件
2. 创建统一的 AppErrorState 组件
3. 创建统一的 AppLoadingIndicator 组件
4. 所有列表页补充空状态
5. 所有网络请求补充错误状态

**验收：**
- 所有页面通过"交互体验审查"

**执行：** 2周

---

#### 方向3：高级主题入口优化

**问题：** 核心付费功能入口不吸引

**优化：**
1. 卡片式入口（显示主题缩略图）
2. 标注"会员专属"
3. 实时预览功能

**验收：**
- 高级主题点击率 >30%
- 付费转化率 >10%

**执行：** 2周

---

### P1 - 提升体验（重要）

#### 方向4：添加页面过渡动画

**问题：** 页面切换生硬

**优化：**
1. 统一页面过渡时长（300ms）
2. 统一过渡曲线（easeInOut）
3. Hero 动画（书籍封面）
4. 底部弹层滑入动画

**验收：**
- 所有页面通过"动画流畅性审查"
- 60fps 流畅度

**执行：** 1-2周

---

#### 方向5：优化高频页面

**高频页面：**
1. 书架页
2. 搜索页
3. 阅读器
4. 我的页面

**优化：**
- 统一卡片样式
- 添加骨架屏
- 优化空状态
- 添加微交互

**执行：** 2周

---

### P2 - 锦上添花（可选）

#### 方向6：微交互优化

**优化：**
- 按钮点击缩放（0.95）
- 列表项进入动画
- 数值变化过渡
- 开关切换动画

**执行：** 1周

---

#### 方向7：桌面端优化

**优化：**
- Hover 状态完善
- 键盘快捷键
- 右键菜单
- 窗口缩放适配

**执行：** 2周

**产出：**
- 所有页面通过交互体验审查

## 🔍 审查流程

### 如何使用这份清单

**1. 选择一个页面**
- 从高频页面开始（书架、搜索、阅读器、我的）

**2. 逐项检查**
- 按"审查清单"逐项打勾
- 记录不合格项

**3. 修复问题**
- 按优先级修复
- P0（视觉、状态）优先

**4. 复查验收**
- 修复后重新审查
- 确保所有项通过

**5. 下一个页面**
- 重复流程
