# Flutter 自适应基线矩阵

更新时间：2026-05-09  
用途：记录阶段 0 的基线口径，为后续阶段改造提供统一对照。  
范围：布局、密度、组件结构与截图检查，不覆盖主题视觉。

## 1. 标准视口

后续自适应开发和验收优先使用以下视口。

- [x] `360x800 @3.0`
  小屏手机基线，用于检查紧凑密度、横向溢出、底部导航遮挡。
- [x] `390x844 @3.0`
  常规手机基线，用于检查默认手机体验。
- [x] `412x915 @3.5`
  大号 Android 手机基线，用于检查首屏信息量。
- [x] `600x960 @2.0`
  中屏基线，用于检查 `NavigationRail`、双栏或更高列数的入口。
- [x] `840x1180 @2.0`
  平板基线，用于检查扩展结构和内容最大宽度。
- [x] `780x360 @3.0`
  手机横屏基线，用于检查高度不足时的紧凑密度。

## 2. 文字缩放矩阵

- [x] `1.0x`
  默认系统字体大小。
- [x] `1.3x`
  放大字体基线，用于检查标题、筛选、按钮和 trailing 控件是否互相遮挡。

## 3. P0 页面基线范围

- [x] 书架页
  重点检查网格列数、搜索栏、筛选 chip、底部导航遮挡和首屏信息量。
- [x] 搜索页
  重点检查输入区、搜索结果卡片、来源状态和批量/筛选操作。
- [x] 阅读设置弹层
  重点检查弹层高度、快捷入口列数、滑块、步进器、开关和横屏可操作性。

## 4. P1 页面基线范围

- [x] 书源页
  重点检查列表密度、状态 badge、导入入口和底部操作遮挡。
- [x] 书籍详情页
  重点检查封面、标题、主操作、简介和目录入口在不同宽度下的结构。
- [x] 设置类页面
  重点检查设置项行高、说明文字、trailing 控件和内容最大宽度。

## 5. 当前主要问题类型

- [x] 外层已有断点，但内层组件仍存在固定尺寸和固定留白
- [x] 手机内部 `390dp`、`480dp` 分档和 `600dp+` 结构断点角色容易混用
- [x] 信息流页面部分区域偏单列放大，没有充分按容器宽度重排
- [x] 设置类页面存在大卡片、大圆角和大 padding 的惯性
- [x] 文字放大、横屏高度不足时缺少统一密度降级规则
- [x] 截图验收分散在 smoke test 和人工检查中，缺少统一矩阵入口
