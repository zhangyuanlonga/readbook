# 桌面端 UI 第一里程碑：外壳导航与我的页展示基线

创建日期：2026-05-31  
阶段名称：Phase 1 - 桌面端 UI 展示基线  
适用平台：桌面端。本文中的桌面端统一包含 Web、Windows、macOS、Linux。  
排除范围：iOS、Android 的 UI、交互、业务流程和验收任务。  
阶段目标：**先定义桌面端如何展示，再逐步接业务能力。**

## 0. 阶段定位

本阶段只负责桌面端 UI 展示基线，不负责复杂业务能力完整兼容。

优先处理：

- 应用外壳。
- 侧边栏导航。
- 页面切换关系。
- 我的页入口和我的模块页面。
- 桌面端布局、弹层、键鼠交互、视口规则。

暂不处理：

- 本地图书导入完整链路。
- 本地图书格式解析。
- PDF / EPUB / MOBI 本地阅读。
- 支付完整链路。
- WebView 登录完整替代。
- 移动端 UI 重构。

## 1. 核心原则

- Web 归入桌面端口径，不单独再写一套 Web UI 规则。
- 桌面端 UI 不能只是移动端页面横向拉宽。
- 侧边栏、内容区、页面标题区、操作区先统一，再进入具体业务链。
- “我的”模块先作为桌面端 UI 样板区，用它验证设置页、资源页、管理页、表单页、列表页、编辑页的桌面展示方式。
- 移动端只作为不可牵扯边界，不进入本阶段任务和验收。

## 3. 桌面端外壳 UI 定义

### 3.1 Shell 结构

桌面端默认结构：

```text
DesktopShell
  ├─ left navigation rail / sidebar
  ├─ optional top page header
  ├─ main content region
  └─ floating task / status entry
```

要求：

- 左侧导航承担一级模块切换。
- 内容区不被拉满到不可读宽度。
- 页面标题和主要操作靠近内容区，而不是依赖手机 AppBar。
- 当前路由选中态必须稳定。
- 侧边栏收起、窄桌面和宽桌面规则需要明确。

### 3.2 导航栏规则

- `>= 840` 默认使用侧边栏或 NavigationRail。
- `600 - 839` 可使用紧凑侧栏或窄 rail。
- `< 600` 只做窄屏兼容，不作为移动端适配任务。
- 一级入口只放高频模块：首页、书架、发现、阅读统计、我的。
- 我的模块内部页面不全部塞进一级侧边栏，应在我的页内部通过分区、二级导航或设置面板进入。

### 3.3 页面标题区

桌面端页面应有稳定标题区：

- 页面标题。
- 简短状态或说明。
- 当前页面主要操作。
- 可选搜索、筛选、布局切换。

手机式透明 AppBar 不作为桌面端默认样式；如果复用，也需要外层约束和桌面端标题区补强。

## 4. 我的页桌面 UI 定义

### 4.1 我的首页

桌面端我的首页建议定义为“个人与设置仪表盘”：

- 左上：用户信息、会员状态、阅读概览。
- 右上：快捷入口或常用操作。
- 下方：外观、数据、其他三类分区。
- 宽屏：卡片网格或双列布局。
- 窄桌面：单列列表，但保持桌面标题区和操作区。

验收重点：

- 页面不无限拉宽。
- 分区密度合理。
- 切换网格 / 列表不导致跳动或溢出。
- 头像、背景、会员等移动端能力入口在桌面端有明确状态。

### 4.2 设置类页面

适用页面：

- 外观设置。
- 系统设置。
- 字体管理。
- 阅读背景。
- 底部导航图标设置。

桌面端布局建议：

- 左侧：设置分组或目录。
- 中间：具体设置项。
- 右侧：预览区或当前配置摘要。

若页面内容较少，可以使用双列；若设置项很多，优先使用左侧目录 + 内容区。

### 4.3 资源管理类页面

适用页面：

- 高级主题。
- 封面图集。
- 启动图集。
- 阅读背景。
- 底部导航图标图集。

桌面端布局建议：

- 列表 / 网格视图。
- 右侧详情或预览面板。
- 顶部工具栏：新建、导入、导出、搜索、筛选。
- Web 不支持的文件能力以禁用态、只读态或说明态展示。

本阶段只定义展示和入口状态，不承诺完成资源导入导出。

### 4.4 表单与详情类页面

适用页面：

- 反馈。
- 关于。
- 会员中心。
- 分类 / 标签管理。

桌面端布局建议：

- 表单最大宽度不超过可读范围。
- 列表和详情可以并排。
- 主按钮位置固定且清晰。
- 弹层优先 dialog / side panel。

## 6. 完成标准

本里程碑开发完成需要满足：

- 桌面端 UI 口径已统一：本文中的桌面端包含 Web。
- 外壳导航栏和内容区规则已明确。
- 我的模块页面已经按类型分组，并有桌面展示方案。
- 页面容器、弹层、键鼠交互和受限能力展示规则已明确。
- 未涉及 iOS / Android UI、交互、原生目录和验收任务。

本里程碑验收完成需要满足：

- 桌面端外壳可打开并切换一级页面。
- 我的首页和至少两个我的子页面完成真实桌面视口验证。
- 页面没有明显无限拉宽、遮挡、按钮溢出或手机式底部弹层误用。
- 不支持能力不会显示为可点击失败入口。
