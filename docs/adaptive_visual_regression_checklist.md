# 自适应视觉回归清单

更新时间：2026-05-11

用途：发布前人工复核 Flutter 自适应改造。不按机型名验收，只按逻辑窗口、方向、文字缩放和页面类型验收。

## 标准矩阵

宽度：

- `360x640`
- `390x844`
- `412x915`
- `600x960`
- `840x1180`
- `780x360` 横屏
- `1024x768`
- `1280x800`
- `1440x900`
- `1920x1080`

文字缩放：

- `1.0x`
- `1.3x`
- `1.5x`，用于发布前专项检查

## 输入方式矩阵

- 纯触控：手机、平板手持模式，重点检查底部导航、弹层拖拽、阅读器点击区。
- 触控 + 键盘：iPad 键盘、Android 平板键盘，重点检查输入框焦点、快捷键不误触、键盘弹出后内容可滚动。
- 鼠标 + 键盘：桌面/Web，重点检查 hover、右键、Tab 顺序、Esc 关闭弹层。
- 触控笔：平板绘制/点击场景，按触控处理，不应只依赖 hover 或右键。

## 动态窗口矩阵

- Android 分屏：窗口从宽到窄时，书架/我的/资源页切回 compact 布局且不丢路由。
- iPad Slide Over / Stage Manager：窗口拖拽缩放时，阅读器正文、目录和设置面板重新布局。
- 桌面窗口拖拽缩放：`600dp`、`840dp`、`1280dp` 断点切换无内容重叠。
- 折叠屏展开/折叠：compact 与 medium/expanded 之间切换不重复触发重任务。

## 桌面交互矩阵

- hover：列表项、图集卡片、任务队列入口、导航 rail 有明确反馈。
- 右键：有上下文菜单的页面不与长按菜单冲突；无右键能力时不报错。
- Tab 顺序：搜索框、筛选、主按钮、列表项操作、弹层按钮顺序可预测。
- 快捷键：阅读器、搜索、设置弹层不抢占系统快捷键。
- Esc：Dialog、任务队列、设置面板可关闭；阅读器沉浸层关闭后不退出页面。

## 显示专项

- Windows 高 DPI 150%：文字和图标清晰，任务队列、缓存页、图集页无位图拉伸。
- 字体缩放 1.5x：设置页、我的页、资源页按钮可换行或滚动，不出现横向溢出。
- 横屏 + 大字体：阅读器工具栏、目录、缓存页操作区不互相遮挡。

## P0 页面

- 书架页：搜索、筛选、网格列数、底部导航遮挡
- 搜索页：关键词输入、筛选条、结果网格、失败提示
- 阅读设置弹层：主设置、界面设置、字体、排版、漫画设置
- 书籍详情页：封面信息、主操作、简介展开、开始阅读按钮

## 关键 Smoke

| 页面 | 必测动作 | 通过标准 |
| --- | --- | --- |
| 书架 | 搜索、筛选、选择、排序、导入入口 | 移动端/桌面端控件可用，不出现置灰误判或重叠 |
| 阅读器 | 打开本地章节、目录、设置、横竖屏切换 | 正文宽度合理，弹层不遮挡关键操作 |
| 我的 | 设置入口、资源入口、任务队列入口 | 宽屏和窄屏入口稳定，任务面板可打开 |
| 搜索 | capability 关闭、needsSetup、supported 三态 | 不创建不可用运行时页面，解释页文案正确 |
| 资源管理页 | 图集、字体、缓存分类刷新 | 首屏不全量扫描，按需刷新和导入任务进入任务队列 |

- 关于页：品牌区、信息项、技术栈标签、官网/更新按钮
- 公告列表/详情页：最新公告卡片、列表项、正文宽度、状态标签
- 错误中心：日志统计、筛选开关、长日志详情、复制/导出/清空按钮
- 登录页：登录/注册切换、输入框、键盘弹出、提交按钮
- 用户资料页：资料卡片、账号状态、刷新/退出按钮窄屏堆叠
- 会员中心：权益列表、底部操作栏、支付/激活/设备管理弹层
- 反馈列表/详情/提交页：搜索筛选、状态标签、详情正文、提交表单和键盘避让

## Motion 检查

- 页面进入是否只做首屏和关键区块，不影响阅读和滚动
- 状态切换是否统一用轻量动画，加载/空态/错误态不跳动
- 底部弹层、Dialog、SnackBar 的出现和消失是否一致
- 阅读器、书架、搜索等高频场景是否避免持续动画
- `MediaQuery.disableAnimations` 下是否保持可用
- 横屏、`600dp+` 和 `1.3x` 文字下是否仍稳定

## 通过标准

- 页面无横向溢出
- 主要按钮完整可见且可点击
- 键盘、手势条、状态栏不遮挡关键内容
- `600dp+` 页面不只是手机单列放大
- `840dp+` 书架、本地书库、详情、我的/设置和阅读设置浮层使用宽屏结构
- `1.3x` 文字缩放下说明文字能换行或滚动
- 横屏高度不足时仍能进入核心设置或核心操作

## 代码守卫

运行：

```bash
dart run tool/check_adaptive_layout_guard.dart lib
```

需要让 CI 在发现新增风险时失败：

```bash
dart run tool/check_adaptive_layout_guard.dart --fail lib
```

脚本会提示两类风险：

- 新增按具体机型名做自适应判断
- 新增大固定尺寸，例如 `EdgeInsets.all(24)`、`BorderRadius.circular(24)`、固定大 `SizedBox`

已有历史命中项需要逐页消化，不要求一次性清零。
