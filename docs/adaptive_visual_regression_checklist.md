# 自适应视觉回归清单

更新时间：2026-05-09

用途：发布前人工复核 Flutter 自适应改造。不按机型名验收，只按逻辑窗口、方向、文字缩放和页面类型验收。

## 标准矩阵

宽度：

- `360x640`
- `390x844`
- `412x915`
- `600x960`
- `840x1180`
- `780x360` 横屏

文字缩放：

- `1.0x`
- `1.3x`

## P0 页面

- 书架页：搜索、筛选、网格列数、底部导航遮挡
- 搜索页：关键词输入、筛选条、结果网格、失败提示
- 阅读设置弹层：主设置、界面设置、字体、排版、漫画设置
- 书籍详情页：封面信息、主操作、简介展开、开始阅读按钮

- 书源页：搜索、分组、批量选择、状态 chip、操作按钮
- 系统设置页：开关项、并发步进器、恢复默认按钮
- 外观设置页：列表密度、卡片间距、二级入口
- 我的页：设置入口、卡片区、底部安全区
- 缓存管理页：统计项、清理按钮、明细弹层、长标签换行
- 本地书库页：导入入口、说明卡片、导入后操作按钮
- 阅读记录页：周期筛选、统计卡片、热力图、长书名/章节名
- 脚本书源编辑页：工具栏、代码区、保存/调试入口、键盘 inset
- 粘贴导入页：输入区高度、导入按钮、剪贴板操作
- 书源登录页：状态提示、表单项、操作按钮、嵌入模式标题栏
- 书源 Web 登录页：顶部完成登录按钮、WebView 底部安全区、错误提示
- 脚本调试页：调试输入、总结卡片、阶段日志、原始输出滚动
- 字体管理页：导入入口、字体卡片、状态 chip、长字体名
- 阅读背景管理页：搜索栏、背景网格、空状态、预览入口
- 封面图库/编辑页：图集列表、图片网格列数、选择/删除状态
- 启动图图库/编辑页：图集列表、图片网格列数、横屏编辑操作
- 底栏图标图库/编辑页：图集列表、批量工具、各 tab 图标配置
- 首页：打卡卡片、阅读目标、继续阅读横向列表、排行区块

- 同步设置页：分段控件、同步按钮、表单按钮换行、内容分组
- 同步历史页：任务列表、冲突列表、详情弹层、长错误文案

## P3 页面

- 关于页：品牌区、信息项、技术栈标签、官网/更新按钮
- 公告列表/详情页：最新公告卡片、列表项、正文宽度、状态标签
- 错误中心：日志统计、筛选开关、长日志详情、复制/导出/清空按钮
- 登录页：登录/注册切换、输入框、键盘弹出、提交按钮
- 用户资料页：资料卡片、账号状态、刷新/退出按钮窄屏堆叠
- 会员中心：权益列表、底部操作栏、支付/激活/设备管理弹层
- 反馈列表/详情/提交页：搜索筛选、状态标签、详情正文、提交表单和键盘避让

## Motion 检查

- 页面进入是否只做首屏和关键区块，不影响阅读和滚动
- 状态切换是否统一用轻量动画，加载/空态/错误态不跳动
- 底部弹层、Dialog、SnackBar 的出现和消失是否一致
- 阅读器、书架、搜索等高频场景是否避免持续动画
- `MediaQuery.disableAnimations` 下是否保持可用
- 横屏、`600dp+` 和 `1.3x` 文字下是否仍稳定

## 通过标准

- 页面无横向溢出
- 主要按钮完整可见且可点击
- 键盘、手势条、状态栏不遮挡关键内容
- `600dp+` 页面不只是手机单列放大
- `1.3x` 文字缩放下说明文字能换行或滚动
- 横屏高度不足时仍能进入核心设置或核心操作

## 代码守卫

运行：

```bash
dart run tool/check_adaptive_layout_guard.dart lib
```

需要让 CI 在发现新增风险时失败：

```bash
dart run tool/check_adaptive_layout_guard.dart --fail lib
```

脚本会提示两类风险：

- 新增按具体机型名做自适应判断
- 新增大固定尺寸，例如 `EdgeInsets.all(24)`、`BorderRadius.circular(24)`、固定大 `SizedBox`

已有历史命中项需要逐页消化，不要求一次性清零。
