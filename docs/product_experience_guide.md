# 产品体验指南

更新时间：2026-04-02
用途：统一 UI、自适应、阅读器体验、字体和主题策略。

## 1. 目标

本指南统一以下主题：

- 手机端适配
- 跨页面布局和组件演进
- 正文质量
- 阅读器交互
- 字体和排版
- 主题系统

当前阶段的核心目标：

- 手机端稳定可用
- 阅读器读起来舒服
- 设置入口清晰，交互稳定

## 2. UI 与自适应口径

### 当前范围

- Android / iOS 手机优先
- 竖屏优先，横屏只保证可用
- 允许在 `600+` 宽度进入中屏布局
- 允许在 `840+` 宽度进入扩展布局
- 不单独维护平板专属页面，但允许在现有页面上做 rail、双栏、限宽和更宽内容区

### 当前断点

项目当前统一以 `AppLayout` 为准：

- `smallPhone`: `width <= 360`
- `regularPhone`: `361-389`
- `largePhone`: `390-479`
- `phoneXl`: `480-599`
- `medium`: `600-839`
- `expanded`: `>= 840`

额外规则：

- `width <= 360` 是全局唯一“小屏特判”阈值
- `600` 是主导航和主要双栏布局切换阈值
- `840` 是扩展布局阈值

### 机型参考

这些区间对应的是逻辑宽度，不是物理分辨率；同一设备也可能因为系统显示缩放、分屏、多窗口、横竖屏变化而落入不同区间。

- `<= 360`
  小屏手机区间。
  常见于老机型、入门安卓、窄宽度窗口、小窗模式。
- `361-389`
  偏小主流手机区间。
  常见于 `375dp` 左右设备和部分中小屏手机。
- `390-479`
  主流手机区间。
  当前大多数 iPhone 标准机型和大量安卓手机落在这一档。
- `480-599`
  超大手机 / 折叠过渡态区间。
  普通直板机较少，更多见于超大屏手机、折叠屏某些窗口态、小平板窄窗。
- `600-839`
  小平板 / 折叠展开态区间。
  适合作为 rail 和双栏的起点。
- `>= 840`
  平板 / 桌面宽窗口区间。
  适合作为扩展布局区间。

### 当前基础设施

- 根节点统一接入 `ResponsiveBreakpoints`
- 全局文字缩放统一做 clamp，避免大字号冲坏布局
- 页面级限宽统一走 `AppLayout.pageContentMaxWidth()`
- 关于页这类特殊页面可使用单独的最大宽度方法
- 页面左右留白、卡片内边距、dialog inset 统一走 `AppSpacing`
- 页面结构统一使用 `AppAdaptiveMetrics.windowClass`
- 组件密度统一使用 `AppAdaptiveMetrics.density`
- 书架、搜索结果和字体选择这类网格优先按最小 item 宽度算列数

### 当前页面级模式

- 主壳层：
  手机使用 `NavigationBar`，`600+` 使用 `NavigationRail`
- 常规设置页：
  `LayoutBuilder + Align(topCenter) + ConstrainedBox(maxWidth) + ListView`
- 书架网格：
  `SliverLayoutBuilder` 按可用宽度动态算列数
- 发现页：
  手机单列，`600+` 双栏，`840+` 放大侧栏和内容区
- 阅读页：
  以单页为主，局部弹层、设置行和底部 sheet 按宽度做密度与结构切换
- 搜索页：
  手机保持单列语义，`600dp+` 结果区进入自适应多列网格
- 书籍详情页：
  手机保持单列，`600dp+` 封面信息、操作和简介进入双区布局

### 设备类型与展示判断

项目内统一按以下 4 层理解展示策略：

- `<= 360`
  定义：小屏特判
  展示：
  压缩 padding、宫格降列、横排按钮改纵排、设置项允许上下堆叠、文案更早折行。
- `361-599`
  定义：手机主布局
  展示：
  单列页面结构为主，只做 spacing 和密度差异，不轻易拆成双栏。
- `600-839`
  定义：中屏布局
  展示：
  主导航切 `NavigationRail`，允许设置页、发现页、信息页进入双栏或 side panel。
- `>= 840`
  定义：扩展布局
  展示：
  保持 rail，增加内容区最大宽度，允许更稳定的双栏和更宽的信息布局。

### 展示判断规则

- 页面级布局：
  优先看 `constraints.maxWidth`
- 组件级密度：
  优先看当前组件可用宽度
- 只有 shell、全局 spacing、系统级能力判断：
  才允许看 `screenWidth(context)`
- 阅读页：
  以阅读稳定性优先，不因设备类型大改主结构，主要做局部密度和弹层结构切换

### 最小验证矩阵

- `360x640`
- `390x844`
- `411x891`
- `600x960`
- `840x1180`
- 字体缩放 `1.0`、`1.3`

验收底线：

- 无溢出
- 按钮可点
- 文本不被状态栏、手势条、键盘遮挡

### 布局原则

- 优先使用约束和滚动兜底
- 长内容优先 `ListView` / `CustomScrollView`
- 受约束子树使用局部宽度
- `SafeArea`、`viewInsets.bottom`、`textScaler` 必须纳入布局判断
- 页面级布局判断优先使用 `constraints.maxWidth`
- 组件处于限宽容器中时，禁止继续使用整屏宽度决定列数、密度和换行
- `screenWidth(context)` 只允许用于 shell、全局 spacing、系统级能力判断这类确实依赖整屏宽度的场景
- 小屏特殊处理只能基于 `width <= 360`

### 编码规则

- 页面骨架优先复用以下模板：
  `LayoutBuilder -> pageContentMaxWidth -> Align -> ConstrainedBox -> ScrollView`
- 列数、栅格、按钮横竖排切换优先封装进 `AppLayout`
- 间距优先复用 `AppSpacing`，新增页面优先读取 `AppAdaptiveMetrics`
- dialog / sheet 宽高优先读取 `AppAdaptiveMetrics.dialogMaxWidth`、`bottomSheetMaxWidth` 和统一高度策略
- 发现页、书架这类内容区布局，密度判断应基于当前内容区宽度而不是整屏宽度
- 禁止新增按具体机型名做适配判断；用 `dart run tool/check_adaptive_layout_guard.dart lib` 做发布前扫描

### 当前结论

- 已统一：`width <= 360` 作为全局小屏特判
- 已统一：限宽容器内的宫格/紧凑布局优先看容器宽度
- 允许保留少量设备级宽度判断，但必须能解释为什么不能改成容器宽度

## 3. 阅读体验基线

### 已完成

- 正文底部遮挡修复
- 换行和段落归一化
- 不可见字符和异常空白过滤
- 阅读页中部点击联动顶栏和底栏
- 目录和设置走底部浮层
- 主题三态和全局主题联动

### 待继续推进

- 正文内容健康校验
- 广告和水印规则库升级
- HTML 转纯文增强
- 分页衔接一致性
- 正文失败定位增强

## 4. 阅读器交互口径

- 默认进入阅读页时只显示正文
- 点击中部联动显示或隐藏工具栏
- 目录和设置不打断当前阅读状态
- 翻章失败时保留当前位置并给出提示

当前交互目标：

- 降噪
- 好找
- 不打断阅读

### 当前已确认的阅读器改造口径

- 文本阅读统一朝“一个文本内容内核 + 滚动/分页渲染委托”收口
- 文本滚动和文本分页只允许在渲染层、动画层、可见范围计算层存在差异
- 漫画阅读仍保留独立路径，不纳入本轮文本阅读内核合并范围
- 正文插图属于正文顺序的一部分，不再使用独立 `images[]` 语义表达
- `images[]` 只保留给纯图片章节或漫画章节
- 分页模式遇到正文插图时，允许在同一文本内核下局部降级渲染，但不允许切回另一套文本业务链路
- 文本阅读进度统一以 `chapterIndex + chapterPosition` 为主，`chapterUrl/chapterId` 仅作为定位辅助和兼容字段
- 阅读页首层菜单只保留高频阅读动作
- 缓存、换源、详情、书架等动作统一降到二级入口，不占据阅读主路径

### 当前阅读器入口分层目标

- 首层入口：目录、进度或定位、主题或界面、阅读设置
- 二级入口：缓存、换源、详情、书架、低频高级设置
- 高级设置：信息栏、自动换源、音量键翻页、背景图、自定义颜色、进阶排版

## 5. 字体、排版与主题

### 字体方向

- 统一字号、字重、字间距、行高、段距
- 后续支持系统字体和用户导入字体
- 在线和本地阅读尽量共用同一套 typography 解析路径

### 主题方向

- 阅读页日夜切换与全局主题联动
- 保留阅读背景的独立表达能力
- 主题模式和主题色可持久化

## 6. 当前体验优先级

### P0

1. 正文内容健康校验
2. 广告和水印规则升级
3. 阅读器统一文本内核和进度口径
4. 字体和排版入口收口
5. 目录弹层和工具栏统一
6. 阅读器背景图上传后增加压缩和尺寸约束
7. 搜索结果卡增加“在读/已在书架”状态标识

### P1

1. 文本滚动与文本分页委托化收口
2. 字体导入与动态加载
3. 阅读页背景和主题细化
4. 翻页和分页一致性细修
5. “我的”页增加阅读统计卡

## 7. 维护规则

- UI、自适应、阅读体验、字体、主题结论统一更新本文件。
- 不再为这些主题分别拆新的路线图文件。
- 新页面若引入新的断点、限宽或密度策略，必须先回写本文件，再落代码。
