# 产品体验指南

更新时间：2026-03-25
用途：统一 UI、自适应、阅读器体验、字体和主题策略。

## 1. 目标

本指南统一以下主题：

- 手机端适配
- 跨页面布局和组件演进
- 正文质量
- 阅读器交互
- 字体和排版
- 主题系统

当前阶段的核心目标：

- 手机端稳定可用
- 阅读器读起来舒服
- 设置入口清晰，交互稳定

## 2. UI 与自适应口径

### 当前范围

- Android / iOS 手机优先
- 竖屏优先，横屏只保证可用
- 不做平板双栏或桌面专用布局

### 当前断点

- `phoneSmall`: `width < 360`
- `phoneNormal`: `width >= 360`

当前阶段只允许在 spacing 和密度上做差异，不鼓励因手机尺寸继续拆更多结构。

### 最小验证矩阵

- `360x640`
- `411x891`
- `480x960`
- 字体缩放 `1.0`、`1.3`

验收底线：

- 无溢出
- 按钮可点
- 文本不被状态栏、手势条、键盘遮挡

### 布局原则

- 优先使用约束和滚动兜底
- 长内容优先 `ListView` / `CustomScrollView`
- 受约束子树使用局部宽度
- `SafeArea`、`viewInsets.bottom`、`textScaler` 必须纳入布局判断

## 3. 阅读体验基线

### 已完成

- 正文底部遮挡修复
- 换行和段落归一化
- 不可见字符和异常空白过滤
- 阅读页中部点击联动顶栏和底栏
- 目录和设置走底部浮层
- 主题三态和全局主题联动

### 待继续推进

- 正文内容健康校验
- 广告和水印规则库升级
- HTML 转纯文增强
- 分页衔接一致性
- 正文失败定位增强

## 4. 阅读器交互口径

- 默认进入阅读页时只显示正文
- 点击中部联动显示或隐藏工具栏
- 目录和设置不打断当前阅读状态
- 翻章失败时保留当前位置并给出提示

当前交互目标：

- 降噪
- 好找
- 不打断阅读

## 5. 字体、排版与主题

### 字体方向

- 统一字号、字重、字间距、行高、段距
- 后续支持系统字体和用户导入字体
- 在线和本地阅读尽量共用同一套 typography 解析路径

### 主题方向

- 阅读页日夜切换与全局主题联动
- 保留阅读背景的独立表达能力
- 主题模式和主题色可持久化

## 6. 当前体验优先级

### P0

1. 正文内容健康校验
2. 广告和水印规则升级
3. 字体和排版入口收口
4. 目录弹层和工具栏统一
5. 阅读器背景图上传后增加压缩和尺寸约束
6. 搜索结果卡增加“在读/已在书架”状态标识

### P1

1. 字体导入与动态加载
2. 阅读页背景和主题细化
3. 翻页和分页一致性细修
4. “我的”页增加阅读统计卡

## 7. 维护规则

- UI、自适应、阅读体验、字体、主题结论统一更新本文件。
- 不再为这些主题分别拆新的路线图文件。
