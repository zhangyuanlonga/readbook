# 书签摘录功能计划（可勾选版）

更新时间：2026-03-14  
目标：在阅读时长按选句并收藏为书签，支持回跳定位，尽量不打断阅读体验。

## 1. 背景与目标
- 让用户在阅读过程中快速收藏喜欢的句子或片段。  
- 选中态与已收藏态视觉区分明确，避免排版抖动。  
- 书签可定位回原文，失败有兜底策略。

## 2. MVP 范围
- 长按正文进入选区模式。  
- 默认自动选中“当前句子”，可拖动把手扩展范围。  
- 底部浮动工具条：收藏书签、复制、分享、取消。  
- 书签列表入口与回跳定位。  
- 本地持久化，不做云同步。

## 3. 非目标（MVP 不做）
- 多色高亮、备注、标签管理。  
- 跨设备同步。  
- 复杂翻页模式下的精准坐标映射。

## 4. 交互与视觉策略
- 选中态：浅色底 + 细下划线。  
- 已收藏态：仅保留浅色底或左侧小书签标记，避免加粗导致排版抖动。  
- 收藏成功轻提示“已收藏”。

## 5. 数据结构建议
- bookmarkId  
- bookId  
- chapterId  
- chapterIndex  
- startOffset  
- endOffset  
- snippet  
- createdAt  
- color（预留，可为空）

## 6. 定位策略
- 优先使用 startOffset / endOffset 回锚。  
- 若失败，使用 snippet 在章节全文搜索定位。  
- 仍失败则跳到章节顶部并提示。

## 7. 技术落点（对齐现有分层）
- domain：Bookmark 实体、BookmarkRepository 接口、Add/List/Remove 用例。  
- data：Drift 表与迁移、Repository 实现。  
- features/reader：选区控制器、工具条组件、书签列表入口与回跳逻辑。

## 8. 验收标准
- 长按可选中句子并成功收藏。  
- 书签列表可见，点击可回跳或提示兜底。  
- 已收藏句子显示稳定视觉标识。  
- 阅读体验无明显卡顿或重排。
