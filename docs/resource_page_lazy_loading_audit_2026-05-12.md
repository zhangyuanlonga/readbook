# 资源页面懒加载审计

更新时间：2026-05-12

## 当前结论

- 图集、启动图、底栏图标页面目前是进入页面后加载列表，不在首屏启动同步 build 全量图片。
- 图片展示侧已使用 `LazyFileImage` 和缩略尺寸参数，滚动列表不会在启动阶段一次性解码所有图片。
- 字体选择已经从外观页常驻加载收口为点击字体选择时加载；字体管理页作为资源页进入后加载列表是可接受的。
- 需要收紧的是启动阶段资源迁移：原来每次启动都会扫高级主题、图集和字体注册表；本轮已增加受管资源路径迁移版本门控，完成后不再每次启动重复扫描。

## 风险点

| 页面/服务 | 当前行为 | 后续建议 |
| --- | --- | --- |
| 封面图集页 | 进入页面加载图集列表 | 图集图片很多时，列表 metadata 分页或延迟读取尺寸 |
| 启动图图库页 | 进入页面加载图集和启用状态 | 大图库预览只读可见项缩略图 |
| 底栏图标图库页 | 进入页面加载图集和当前启用项 | 图标包很多时拆成索引列表 + 展开加载图片 |
| 字体管理页 | 进入页面加载注册字体 | 字体文件 metadata 和预览字形按展开或选中加载 |
| 缓存管理页 | 进入页面展示清理入口 | 缓存体积统计按卡片展开或点击刷新，不在页面 build 中全量扫描 |
| 受管资源路径迁移 | 版本门控后只在新迁移版本执行 | 新增迁移必须提升版本号，并说明扫描范围 |

## 后续阶段

### R1：图库资源分页

- [ ] 为图集服务补轻量 index 模型，只包含 id、名称、数量、首图。
- [ ] 编辑/详情页再加载完整图片列表。
- [ ] 图片尺寸、文件存在性校验放到可取消的后台任务。

### R2：字体资源延迟 metadata

- [ ] 字体管理页首屏只展示注册表字段。
- [ ] 字体预览、文件大小、校验结果在卡片进入视口或展开时加载。
- [ ] 字体导入任务接入 `AppTaskStatusKind.fontImport`。

### R3：缓存资源按需统计

- [ ] 缓存页默认不扫描全部目录。
- [ ] 每个缓存分类提供单独刷新入口。
- [ ] 大目录扫描接入统一任务态，允许取消或后台完成。

## 验收规则

- App 启动阶段不得无版本门控地扫描图集、字体、缓存目录。
- 资源列表必须使用 builder/sliver builder，不允许 `children` 一次性创建大量资源项。
- 图片文件必须由懒加载组件展示，不得在页面 build 中同步读取文件字节。
- 资源 metadata 读取失败不能阻塞页面进入。
