# Selune 品牌与设计规范

更新时间：2026-06-07  
用途：作为 `Selune` 品牌视觉、界面主题、官网设计和营销素材的统一参考；同时明确默认应用主题与品牌露出边界，避免把重品牌色误用到所有页面。

## 1. 品牌定位

`Selune` 是一个偏轻阅读方向的产品品牌，强调安静、精致、轻盈和可信赖，而不是传统工具型阅读器的功能堆叠感。

目标气质：

- 轻：界面呼吸感足，避免沉重和拥挤。
- 静：视觉节奏稳定，减少喧闹和过度刺激。
- 柔：适合女性用户，也保留中性高级感。
- 精：通过细节、留白、材质感和对比建立质感。
- 品牌化：名字、图标、页面和官网风格统一，不走通用工具外观。

一句话描述：

`Selune 是一个带有月光质感的轻阅读品牌。`

## 2. 品牌关键词

推荐统一使用的视觉与文案关键词：

- Moonlit
- Quiet luxury
- Soft premium
- Light reading
- Calm contrast
- Warm paper
- Graphite elegance

不推荐的关键词：

- 硬核工具
- 极客效率
- 科幻霓虹
- 少女粉萌系
- 华丽奢侈金属风

## 3. 品牌配色

### 3.0 默认应用主题与品牌预设关系

应用内默认视觉基调优先保持当前移动端已经验证好看的 `霁雪白` 主题：干净、轻、低噪点、偏系统感但不冰冷。`Selune` 配色是可选主题和历史品牌参考，不是要求登录、书架、搜索、阅读器等高频业务页默认使用重品牌色。

后续设计和开发默认遵守：

- 默认主题：继续以 `霁雪白` 的清爽浅色基底为应用主体验，除非产品明确决定切换。
- `Selune` 主题：作为可选主题预设保留，不代表当前默认应用视觉。
- 高频业务页：优先跟随当前 `ThemeData` / `ColorScheme`，不要为了品牌感硬塞固定品牌色或大面积品牌渐变。
- 登录 / 注册页：属于应用入口和账号业务页，默认应延续应用当前主题气质，只做低声量品牌识别，不做营销式品牌海报。

### 3.1 Selune 主题预设色

应用内主题预设已经落地为 `Selune`，核心值如下。注意：这是可选品牌主题，不是当前默认主题。

#### 浅色主题

- Primary: `#AA8552`
- Primary Container: `#F2E4CC`
- Surface: `#F7F3EC`
- Surface Container: `#F2ECE1`
- On Surface: `#1E1A16`
- Outline: `#D4C8B6`

#### 深色主题

- Primary: `#E6CCA0`
- Primary Container: `#6B5230`
- Surface: `#17171C`
- Surface Container: `#202028`
- Surface Container High: `#2A2A32`
- On Surface: `#F5EEE4`
- Outline: `#4C453B`

### 3.2 用色原则

- 浅色模式是主场景，默认应用浅色优先保留 `霁雪白` 的清爽感。
- 固定深色、固定金色等方案不作为当前页面落地要求。
- 常规页面底色优先使用当前主题 token；不要在页面里直接硬编码品牌色替代主题色。
- 禁止把品牌主色替换成偏紫、偏荧光、偏高饱和糖果色。

## 4. 品牌图标方向

### 4.1 主方向

推荐图标结构：

- `月弧 + 书页弧线 + 隐藏 S`

建议理解：

- 月弧代表 `Selune` 的名字联想和夜读感。
- 下方弧线代表纸页、阅读和轻柔翻页。
- 整体走势可隐约形成一个 `S`，增强品牌独特性。

### 4.2 图标风格要求

- 造型简洁，不要堆过多细节。
- 强调留白与轮廓，不做复杂写实插画。
- 不直接画传统厚书本图标。
- 不在 app icon 中放全称文字。
- 保持 iOS 图标语境下的精致感和材质层次。

### 4.3 图标材质建议

图标材质以当前项目已有资源和实际落地效果为准，不在本文强制指定固定底色或主体色。后续若重新设计图标，应先以小范围视觉稿确认方向，再同步更新本文。

## 5. 界面气质规范

## 5.1 整体方向

应用和官网都建议采用：

- 大留白
- 低噪点视觉
- 细描边
- 低强度阴影
- 大圆角
- 层级靠明度和材质区分，而不是靠强烈颜色区分

不建议：

- 大面积渐变铺满
- 很重的卡片阴影
- 复杂拟物
- 五颜六色的功能入口
- 按钮和标签过多导致的页面噪音

### 5.2 页面基底

常规应用页面建议：

- 默认跟随 `Theme.of(context).colorScheme`，优先使用 `surface`、`surfaceContainerLowest`、`surfaceContainerLow`、`outlineVariant`。
- 当前默认移动端视觉以 `霁雪白` 为主，不要为了品牌文档把页面底色强行改成 `Selune` 暖纸色。
- 高频业务页靠留白、细描边、低噪点和主题 token 建立质感，不靠大面积深色块或金色强调。

特殊页面建议：

- 优先复用当前主题 token 和已有品牌资源。
- 如需强化品牌露出，应先针对具体页面确认视觉方案，不默认套用固定配色组合。

### 5.3 组件建议

按钮：

- 常规业务页主按钮跟随当前主题 `primary / onPrimary`。
- 不为品牌感单独指定固定按钮配色；确需特殊按钮时按具体页面单独评审。
- 次按钮优先描边和浅底，不要高饱和
- 圆角建议保持圆润，避免尖锐硬边

卡片：

- 统一大圆角
- 低阴影或无阴影
- 用浅描边和表面层次代替厚投影

标签：

- 使用小写或首字母大写都可以，但语气要轻
- 胶囊形优先
- 不要出现过多高彩色状态标签

输入框：

- 保持透明或低填充
- 以描边和聚焦高亮建立状态
- 避免默认强蓝色高亮

## 6. 字体与排版建议

### 6.1 品牌字标与官网标题

建议方向：

- 带一点现代衬线感的标题字体
- 参考气质：优雅、安静、女性友好、不过分复古

适合的方向：

- 高级衬线
- 柔和现代 Roman
- 时尚杂志感标题字体

### 6.2 应用内正文与系统界面

建议方向：

- 清晰的现代无衬线
- 字重不要过粗
- 中文建议保持中性和易读，不要花哨

### 6.3 排版原则

- 标题不宜过密，字距可略微放松
- 正文强调可读性和行距舒展
- 页面信息块宁可少，不要密
- 文案尽量短句，保持轻呼吸感

## 7. 文案语气

`Selune` 的文案不应是“硬推销”或“功能说明书”口吻，更适合温和、克制、有审美感的表达。

推荐语气：

- 温和
- 自信
- 轻声量
- 不卖弄术语
- 不过分煽情

推荐示例：

- 轻一点，读得更久一点。
- 安静地读，慢慢地沉进去。
- 把阅读留给真正重要的内容。

不推荐示例：

- 最强阅读神器
- 全网最快最全
- 极致效率提升工具

## 8. 官网与营销素材规范

### 8.1 官网首页方向

首页建议结构：

1. 白或暖白背景打底
2. 居中品牌区，突出图标与字标
3. 用 1 到 2 个主卖点，不要过度铺功能
4. 截图和品牌图形优先沿用当前应用视觉，不强行套固定品牌色

### 8.2 小红书方向

如果面向女性用户和审美型传播，建议：

- 视觉避免太技术化
- 多使用安静留白和柔和光感
- 标题封面优先保持暖白、低噪点和清晰标题层级
- 图片要像“生活方式产品”，不是“功能说明页”

### 8.3 应用商店素材方向

- 首图突出图标和名字
- 截图里品牌色只做点睛
- 封面文案保持短句
- 强调阅读氛围和舒适感，不要只堆功能点

## 9. 应用内落地建议

当前项目默认移动端视觉已经具备较干净的 `霁雪白` 基础，后续品牌推进应在这个基础上做低声量统一，而不是把所有页面改成重品牌风。

后续优先建议：

1. 默认主题继续保留当前 `霁雪白` 气质，除非产品明确决定切换。
2. `Selune` 主题继续作为可选品牌预设保留。
3. 启动页、图标、官网和营销页面如需调整，应以当前项目实际资源和单独视觉稿为准，不默认套用固定品牌色组合。
4. About / Mine / 会员页如需强化品牌露出，应以不影响书架、搜索、阅读器、登录等高频业务页的清爽体验为前提。
5. 登录 / 注册页默认跟随当前主题背景和控件 token，只保留轻量品牌名、图标或短句，不使用大面积品牌渐变。

不建议一步到位全部改成重品牌风，否则会影响阅读场景的实用性，也会误导后续 UI 任务。更合理的是：

- 主页面保留清爽可读
- 品牌表达保持低声量
- 阅读器主题继续保留多样化选择
- 所有页面优先读主题 token，不在局部硬编码品牌色

## 10. 设计 Do / Don't

### Do

- 常规应用页使用当前主题的浅色表面和低对比描边
- 品牌相关页面也优先复用当前主题和已有资源
- 特殊品牌色需先有明确设计方案再落地
- 用留白和细节建立高级感
- 让图标和页面语言保持一致

### Don't

- 不要大面积纯黑界面
- 不要做俗气金色渐变
- 不要把 `Selune` 品牌预设误认为全应用默认主题
- 不要把登录、书架、搜索、阅读器等高频页做成营销海报
- 不要使用默认紫色作为品牌第一印象
- 不要把阅读产品做成效率工具软件风
- 不要把品牌元素铺得满屏都是

## 11. 设计交付简表

后续无论是应用页面、官网还是营销图，建议统一先回答这几个问题：

1. 当前设计是品牌触点，还是阅读触点？
2. 当前场景应跟随默认 `霁雪白` 应用主题，还是使用 `Selune` 品牌预设？
3. 当前页面是高频业务页，还是官网 / 营销 / 会员 / 关于等品牌展示页？
4. 是否存在为了品牌感硬塞固定配色、压过主要业务体验的问题？
5. 这个页面看起来是否仍然安静、干净、可信，而不是过度品牌化？

如果不能回答第 2 和第 3 个问题，先不要套用重品牌色，优先沿用当前主题 token。
