# 底栏图集开发计划

更新时间：2026-04-10  
用途：把“底栏图集”从想法整理成可执行的分阶段任务清单，支持后续逐项打勾推进。

## 1. 目标口径

本功能目标：

- 为应用新增“底栏图集”能力
- 用户可新增图集，并为当前底部导航 4 个入口分别配置图标
- 每个入口支持 4 种状态：
  - 日间未选中
  - 日间选中
  - 夜间未选中
  - 夜间选中
- 标准底栏和苹果风格 Dock 使用同一套图标解析逻辑
- 用户可以设置一套默认图集，并在日间/夜间主题下自动切换对应图标

本期只做：

- 本地图集管理
- 默认图集
- 自定义图集骨架
- 标准底栏 / Dock 接入图集

本期不做：

- 云同步
- 导入导出
- 图集分享
- 按分类/页面绑定图集

## 2. 格式规则

图标格式约定：

- [x] 首选支持 `SVG`
- [x] 兼容支持 `PNG`
- [ ] 暂不支持 `JPG / WEBP / GIF`

资源规范约定：

- [ ] 图标画布统一为正方形
- [ ] 建议尺寸统一为 `64x64` 或 `96x96`
- [ ] 要求透明背景
- [ ] 图标主体居中，四周保留安全边距
- [ ] 不建议自带底板或大面积背景块

回退规则约定：

- [ ] 夜间图标缺失时，回退到日间同状态图标
- [ ] 选中图标缺失时，回退到同主题的未选中图标
- [ ] 资源无法解析时，回退到系统默认图标

## 3. 数据模型

### 阶段 A：定义数据结构

- [ ] 新建底栏图集实体
  建议：`BottomNavIconGallery`
- [ ] 新建底栏单项图标配置实体
  建议：`BottomNavIconSet`
- [ ] 新建图标资源引用实体
  建议：`BottomNavIconAssetRef`
- [ ] 明确图集主键、名称、创建时间、更新时间字段
- [ ] 明确“当前启用图集”存储字段
- [ ] 明确图集是否内置、是否可编辑、是否可删除字段

建议数据结构至少包含：

- 图集基本信息
- 每个 tab 的图标配置
- 资源类型：`svg / png`
- 资源路径：本地文件或内置资源路径

### 阶段 B：定义 tab 映射

- [ ] 明确与现有 4 个底栏 tab 的映射
  - `bookshelf`
  - `discover`
  - `stats`
  - `mine`
- [ ] 定义统一 tab key，不允许标准底栏和 Dock 各自维护一份

## 4. 存储与资源管理

### 阶段 C：本地存储骨架

- [ ] 选择本地存储方案
  建议：一期优先 `SharedPreferences + 应用支持目录文件`
- [ ] 图集元数据走结构化存储
- [ ] 图标资源文件存入应用私有目录
- [ ] 为图标资源建立稳定文件命名规则
- [ ] 支持删除图集时一并清理无引用资源

### 阶段 D：资源导入与校验

- [ ] 支持从文件选择器导入 `svg/png`
- [ ] 导入时校验扩展名
- [ ] 导入时校验文件是否为空
- [ ] 对 PNG 做最小尺寸和透明背景建议提示
- [ ] 对 SVG 做基本可解析校验
- [ ] 为导入失败提供清晰错误提示

## 5. 图标解析层

### 阶段 E：抽离图标来源

- [ ] 从当前硬编码 `IconData` 迁出图标来源
- [ ] 新建统一解析器
  建议：`BottomNavIconResolver`
- [ ] 输入参数至少包含：
  - tab
  - 是否选中
  - 当前亮暗主题
  - 当前启用图集
- [ ] 输出统一的可渲染图标描述对象
  建议不要直接返回 `IconData`

### 阶段 F：标准底栏接入

- [ ] 标准 `NavigationBar` 改为走图标解析层
- [ ] 支持 `selectedIcon / icon` 两套图标输出
- [ ] 图集缺失时回退到现有默认图标

### 阶段 G：苹果 Dock 接入

- [ ] `CupertinoDockNavigationBar` 改为走同一套图标解析层
- [ ] 删除 Dock 自己的硬编码图标映射
- [ ] 保证标准底栏与 Dock 图标源完全一致

## 6. 默认图集

### 阶段 H：内置默认图集

- [ ] 新建一套系统默认图集定义
- [ ] 默认图集覆盖 4 个 tab 的 4 种状态
- [ ] 默认图集不可删除
- [ ] 用户未配置任何图集时默认启用系统图集
- [ ] 支持未来新增多套内置图集

### 阶段 I：默认图集回退策略

- [ ] 图集解析失败时回退到内置默认图集
- [ ] 内置默认图集资源缺失时再回退到当前 Material/Cupertino 图标

## 10. 建议执行顺序

建议按下面顺序推进：

1. 先完成阶段 A 到 D
2. 再完成阶段 E 到 G，把解析层和两套底栏接通
3. 然后完成阶段 H 到 I，稳定默认图集能力
4. 再做阶段 J 到 N，把管理页和编辑页搭起来
5. 最后完成阶段 O 到 Q，补测试和验收
