# 文档归档

更新时间：2026-04-26  
用途：存放已完成、已过期、已被上层指南吸收的阶段性计划、审计、清单和库存文档。

## 归档规则

以下类型默认进入归档：

- 带明确阶段日期的执行计划
- `todo` / `inventory` / `baseline` / `task_list` / `checklist`
- 已被工程指南、产品指南或架构约束吸收的专题方案
- 只用于某一轮重构排查的审计文档

## 使用方式

- 当前开发先看 `docs/README.md`
- 只有在需要追溯历史决策、查看旧方案背景时，再进入本目录
- 归档文档默认不再作为当前开发口径
