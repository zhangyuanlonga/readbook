# 阅读器设置迁移清单

更新时间：2026-04-25
用途：在保留旧设置 UI 的前提下，明确哪些能力继续留在阅读器内，哪些迁到 app 级设置，哪些旧入口后续合并或移除。

## 1. 当前执行口径

- 旧设置 UI 继续作为主入口。
- `ReaderSettingsGroups + ReaderSettingsPresetService` 继续作为底层语义模型。
- 阶段 G 的分页引擎 / 分页缓存拆分继续保留。
- 新 `reader_settings_sheet.dart` 暂时作为分组化重构承接层，不直接替换旧 UI。

## 2. 保留在阅读器内

这些能力和“当前阅读会话即时体验”强耦合，应继续留在阅读器设置里：

- 主题 / 亮度 / 背景色 / 纸张风格
- 自定义背景、预设背景、背景即时预览
- 字号、字体、字重、行距、段距、字距、缩进、正文边距
- 正文装饰：文字颜色、斜体、阴影、下划线
- 信息栏与章节头：页眉 / 页脚、信息项、章节头位置
- 翻页交互：点击 / 滑动 / 滚动、翻页动画、音量键翻页
- 漫画专属：漫画模式、图片间距、加载策略
- 自动阅读：速度与阅读时行为

原因：

- 用户通常在阅读中即时调节
- 调整结果需要立刻在当前页面生效
- 这些项天然属于“每本书 / 当前会话”的阅读体验配置

## 3. 迁到 App 级设置

这些能力更像“全局资源管理”或“默认策略”，建议移到 app 设置页：

- 自定义字体资源管理
  说明：阅读器里保留“选择已安装字体”，但字体导入 / 删除 / 维护移到 app 级
- 阅读默认 preset
  说明：新书默认主题、默认字号、默认信息样式、默认边距等应由 app 统一配置
- 全局缓存策略
  说明：如默认预加载、缓存目录清理、空间占用策略
- 换源排序 / 评分全局策略
  说明：`switchSourceScoreRankingEnabled` 更像全局偏好，不是单次阅读设置

## 4. 后续合并或移除的旧入口

这里指移除“重复入口”或“空壳入口”，不是移除能力本身：

- `quick_typography_spacing`
  说明：和排版详细设置高度重复
- `quick_margins`
  说明：和边距详细设置重复
- `quick_info`
  说明：和信息栏详细设置重复
- `appearance`
  说明：与主题 / 正文装饰 / 背景分散重复
- `advanced`
  说明：当前更多是兜底页，信息密度低
- `cache`
  说明：当前是说明页，不是真正的设置能力

## 5. 不应删除的旧能力

以下能力虽然未来可以重做 UI，但不应先删：

- 自定义背景导入与切换
- 背景预设图库
- 自定义字体选择
- 正文字体装饰调节
- 信息栏 margin / padding 微调
- 自定义正文边距
- 自动阅读速度调节
- 漫画阅读模式与加载策略

## 6. 推荐迁移顺序

1. 保持旧设置 UI 为主入口，恢复所有成熟能力可用
2. 让旧 UI 的数据读写统一走 `ReaderSettingsGroups + PresetService`
3. 把重复入口先合并，不删具体能力
4. 把“资源管理类”能力单独迁到 app 设置
5. 等旧 UI 内的能力真正按语义分组稳定后，再决定是否切到新设置壳层

## 7. 当前建议

- 短期：旧设置 UI 保留并继续开发
- 中期：只拆底层，不强推 UI 替换
- 长期：删掉重复入口，而不是删掉旧能力
