# 书架分类与标签联动开发计划

更新时间：2026-04-17  
状态：规划中  
目标：把书架从“顶部筛选栏”升级成“左上角视图切换器”，让用户通过分类和标签快速切换书架显示范围。

## 背景

当前书架已经有一套可用的筛选逻辑：

- 基础筛选：`全部 / 本地 / 小说 / 漫画`
- 标签筛选：基于书籍标签进行切换
- 顶部现状：`全部 + 筛选` 入口

当前“我的 -> 常用”里也已经新增了：

- `标签管理`
- `分类管理`

下一步目标不是继续堆叠“筛选”入口，而是把书架首页左上角升级为：

- `书架 v`
- 或当前分类名 / 标签名 + `v`

点击后从底部弹出一个统一的“书架视图切换器”。

## 目标形态

- [ ] 书架左上角标题从固定 `书架` 改成 `当前视图名 + 下拉箭头`
- [ ] 点击标题后，从底部弹出“书架视图切换面板”
- [ ] 用户可以在三类视图中切换：
  - [ ] 默认视图
  - [ ] 分类视图
  - [ ] 标签视图
- [ ] 切换后书架列表即时刷新
- [ ] 左上角标题同步显示当前视图名
- [ ] 旧的 `全部 + 筛选` 入口逐步移除，避免重复

## 交互草案

### 书架页标题

- [ ] 默认显示：`书架 v`
- [ ] 进入某个分类后显示：`玄幻 v`
- [ ] 进入某个标签后显示：`已读 v`

### 底部切换器

- [ ] 分组 1：默认
  - [ ] 全部
  - [ ] 本地
  - [ ] 小说
  - [ ] 漫画
- [ ] 分组 2：分类
  - [ ] 显示用户自定义分类
  - [ ] 显示 `未分类`
- [ ] 分组 3：标签
  - [ ] 显示用户标签
  - [ ] 显示 `未打标签`
- [ ] 每个条目显示数量，如：`玄幻 12`
- [ ] 当前选中项有明显高亮

## 数据模型原则

### 视图状态

- [ ] 抽一个统一的书架视图状态模型，例如 `BookshelfViewSelection`
- [ ] 统一表达三类视图：
  - [ ] `base`
  - [ ] `category`
  - [ ] `tag`
- [ ] 书架过滤逻辑只认这一套状态，不再分散依赖 `_activeFilter + _activeCustomTag`

### 分类与标签

- [ ] 标签继续保留当前“多标签挂书”的能力
- [ ] 书架当前视图先只支持“单个标签视图”
- [ ] 分类建议是“单分类挂书”
- [ ] 如果当前分类尚未真正挂到书籍实体，需要先补数据模型

验收：

- [ ] 分类如果目前只是管理页入口，没有挂到书籍实体，工作量会明显增大
- [ ] 当前标签筛选和顶部筛选栏逻辑耦合较深，改造时要防止已有标签功能回退
- [ ] 本次建议先支持“单分类 / 单标签视图”，不要第一版就做多条件组合筛选
