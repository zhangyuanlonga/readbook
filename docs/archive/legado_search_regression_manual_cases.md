# legado 搜索/换源手测回归用例（2026-03-02）

## 1. 搜索聚合与排序

步骤：
1. 打开搜索页，输入同一本书关键词（例如：凡人修仙传）。
2. 保持“同书聚合（书名+作者）= 开”。
3. 观察结果列表是否同书聚合为单条，并展示命中源数徽标。
4. 开启/关闭“精准匹配”，对比排序变化。

预期：
1. 同书多源命中时只显示一条，徽标为命中源数量。
2. 精准命中结果在前，包含命中在后。
3. 关闭聚合开关后，结果恢复为逐源明细。

## 2. 分组空结果兜底

步骤：
1. 开启精准匹配并限制部分书源后，搜索一个边界关键词。
2. 触发“有原始结果但当前分组无可展示结果”的场景。
3. 点击“关闭精准匹配”或“切换全部书源”。

预期：
1. 出现对应空结果提示与兜底按钮。
2. 点击按钮后结果列表可恢复显示（条件放宽后）。

## 3. 详情页命中源切换

步骤：
1. 从聚合搜索结果进入书籍详情。
2. 点击右上角“切换来源”。
3. 在面板中选择另一命中源。

预期：
1. 切换成功后详情与目录刷新到目标书源。
2. 失败时保持原来源并提示失败信息。
3. 无需重新回到搜索页全局搜索。

## 4. 阅读中换源定位

步骤：
1. 阅读到中间章节（如第 80 章）。
2. 发起换源，选择章节更少/更全的候选源各一次。
3. 观察切换后章节落点与风险提示。

预期：
1. 标题可匹配时优先按标题定位。
2. 无标题命中时按原索引兜底并做边界裁剪。
3. 目标目录明显落后时给出继续切换确认。

## 5. 自动换源（系统设置）

步骤：
1. 在系统设置打开“自动换源（正文加载失败时）”。
2. 阅读时人为触发当前源正文加载失败。
3. 再关闭该开关重复一次。

预期：
1. 开启时会自动尝试候选源（受尝试上限控制）。
2. 关闭时仅提示失败，不自动切源。

## 6. 回归命令

执行：
1. `flutter analyze`
2. `flutter test`

预期：
1. 分析无错误。
2. 全量测试通过。
