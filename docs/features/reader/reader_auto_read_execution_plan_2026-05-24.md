## 2. 目标结论

本次改造目标是：移除阅读器底部导航栏的「设置」入口，在「目录」和「界面」之间新增「自动」入口，让用户可以一键开启自动阅读，并在首次使用时完成速度、方式、停顿和结束行为配置。

建议底部导航顺序：

1. 目录
2. 自动
3. 界面
4. 夜间/日间

当前代码已经具备部分自动阅读基础能力：

- `ReaderSettings.autoReadEnabled`
- `ReaderSettings.autoReadSpeed`
- `ReaderAutoReadCoordinator`
- `_toggleAutoReadSession()`
- `_startAutoReadSession()`
- `_stopAutoReadSession()`
- `_buildAutoReadIndicator()`
- 自动阅读相关单元测试

因此本次不是从零实现，而是把现有“滚动型自动阅读雏形”升级为完整业务能力。

## 3. 产品口径

- [ ] 产品口径已确认

### 3.1 功能定位

- [ ] 自动阅读用于让用户无需手动翻页，内容按设定节奏自动滚动或自动翻页。
- [ ] 支持典型场景：吃饭、通勤、运动、睡前、速读。
- [ ] 开启后必须有明确状态反馈：图标高亮、速度指示、暂停/结束提示。

### 3.2 底部导航变更

- [ ] 移除底部导航栏「设置」入口。
- [ ] 在「目录」和「界面」之间插入「自动」入口。
- [ ] 保留「界面」入口，用于字体、背景、排版、页眉页脚等视觉配置。
- [ ] 保留「夜间/日间」快捷入口。
- [ ] 若阅读模式不支持自动阅读，自动入口置灰或点击后展示明确提示。

### 3.3 自动阅读参数

- [ ] 翻页方式：自动滚动、自动翻页。
- [ ] 速度：1-10 档，内部映射到滚动 px/s 或翻页停留时长。
- [ ] 停顿模式：不停顿、章节结束停顿、段落结束停顿。
- [ ] 结束后行为：停止、循环本书、下一本书。
- [ ] 首次使用弹出设置面板。
- [ ] 非首次使用按上次配置直接开启。

### 3.4 运行交互

- [ ] 屏幕任意位置点击：暂停自动阅读。
- [ ] 暂停后点击播放：继续自动阅读。
- [ ] 长按屏幕：弹出速度调节滑块，不退出自动模式。
- [ ] 手动上滑/下滑：临时暂停自动阅读。
- [ ] 文本选择、书签、划线、笔记：自动暂停，操作结束后允许手动恢复。
- [ ] 音量键翻页：自动阅读中仍可手动翻页，翻页后按策略继续或短暂停顿。
