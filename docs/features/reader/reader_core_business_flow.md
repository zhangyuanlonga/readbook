## 📋 业务流程概览

阅读器核心业务流程分为 **5 个主要流程**：

1. **打开书籍流程** - 从书架到阅读器
2. **章节导航流程** - 章节切换和跳转
3. **阅读交互流程** - 翻页、滚动、手势
4. **设置调整流程** - 个性化设置
5. **内容加载流程** - 章节内容获取和渲染

## 🔄 流程 1: 打开书籍流程

### 业务流程图

```
用户操作
   ↓
[点击书架上的书] 
   ↓
   ├→ 本地书？
   │    ↓ 是
   │    [读取本地书记录]
   │    ↓
   │    [检查索引状态]
   │    ├→ ready？
   │    │   ↓ 是
   │    │   [加载第一章/上次位置]
   │    │   ↓
   │    │   [进入阅读器]
   │    │
   │    └→ 否 (pending/indexing/failed)
   │        ↓
   │        [跳转详情页] → 提示索引中/失败
   │
   └→ 在线书？
        ↓ 是
        [检查缓存]
        ├→ 有缓存？
        │   ↓ 是
        │   [读取缓存章节]
        │   ↓
        │   [进入阅读器]
        │
        └→ 无缓存
            ↓
            [跳转详情页] → 加载章节列表
```

### 关键步骤说明

#### 步骤 1: 获取书籍信息
- 从 bookshelf_book 表读取基础信息
- 判断书籍类型（本地/在线）
- 读取上次阅读进度

#### 步骤 2: 本地书检查
- 检查 local_book 表的 indexStatus
- **ready**: 可以直接打开
- **pending/indexing**: 跳转详情页，等待索引
- **failed**: 跳转详情页，提示重建索引

#### 步骤 3: 在线书检查
- 检查是否有目录快照（toc_snapshot）
- 检查是否有阅读进度（reading_progress）
- 有任意一个即可打开，否则跳转详情页

#### 步骤 4: 进入阅读器
- 加载章节内容
- 恢复阅读位置
- 初始化阅读器 UI

### 性能指标

| 场景 | 目标时间 | 当前时间 |
|------|---------|---------|
| 本地书打开 | < 500ms | ~300ms ✅ |
| 在线书打开（有缓存） | < 800ms | ~600ms ✅ |
| 在线书打开（无缓存） | < 2s | ~1.5s ✅ |

## 🔄 流程 2: 章节导航流程

### 业务流程图

```
用户操作: 切换章节
   ↓
   ├→ 方式1: 翻到章节末尾
   │    ↓
   │    [检测到页尾]
   │    ↓
   │    [自动加载下一章]
   │    ↓
   │    [显示章节切换提示]
   │    ↓
   │    [继续阅读]
   │
   ├→ 方式2: 通过目录跳转
   │    ↓
   │    [打开目录]
   │    ↓
   │    [选择目标章节]
   │    ↓
   │    [检查章节是否缓存]
   │    ├→ 已缓存
   │    │   ↓
   │    │   [直接跳转]
   │    │
   │    └→ 未缓存
   │        ↓
   │        [显示加载中]
   │        ↓
   │        [获取章节内容]
   │        ↓
   │        [跳转并渲染]
   │
   └→ 方式3: 进度条拖动
        ↓
        [拖动进度条]
        ↓
        [实时显示章节预览]
        ↓
        [松手确认]
        ↓
        [跳转到目标位置]
```

### 章节预加载策略

```
当前章节: N
   ↓
[预加载策略]
   ├→ 前一章 (N-1): 低优先级，后台加载
   ├→ 当前章 (N):   已加载
   └→ 后一章 (N+1): 高优先级，提前加载

预加载时机:
- 阅读到当前章节 70% 时，开始加载 N+1
- 阅读到当前章节 30% 时，开始加载 N-1
- 避免用户等待
```

| 目录跳转（有缓存） | < 300ms | ~250ms ✅ |
| 目录跳转（无缓存） | < 1s | ~800ms ✅ |
| 进度条拖动 | < 500ms | ~400ms ✅ |

## 🔄 流程 3: 阅读交互流程

### 翻页模式流程

```
用户操作: 点击/滑动翻页
   ↓
[检测手势]
   ├→ 点击右侧 → 下一页
   ├→ 点击左侧 → 上一页
   ├→ 左滑 → 下一页
   ├→ 右滑 → 上一页
   └→ 点击中间 → 唤出菜单

翻页逻辑:
   ↓
[当前位置]
   ├→ 在章节中间
   │    ↓
   │    [计算下一页位置]
   │    ↓
   │    [执行翻页动画]
   │    ↓
   │    [更新阅读进度]
   │
   └→ 在章节末尾
        ↓
        [加载下一章]
        ↓
        [章节切换动画]
        ↓
        [显示章节名称]
```

### 滚动模式流程

```
用户操作: 上下滑动
   ↓
[监听滚动事件]
   ↓
[实时更新位置]
   ↓
[检测章节边界]
   ├→ 滚动到章节末尾
   │    ↓
   │    [自动加载下一章内容]
   │    ↓
   │    [无缝追加到底部]
   │
   └→ 滚动到章节开头
        ↓
        [自动加载上一章内容]
        ↓
        [无缝追加到顶部]
```

### 手势优先级

| 手势 | 区域 | 响应 | 优先级 |
|------|------|------|--------|
| 点击中间 | 中间 50% | 唤出菜单 | 最高 |
| 长按 | 全屏 | 文本选择 | 高 |
| 左右滑动 | 左右 25% | 翻页 | 中 |
| 双指缩放 | 全屏 | 调整字号 | 中 |
| 上下滑动 | 滚动模式 | 滚动内容 | 高 |

## 🔄 流程 5: 内容加载流程

### 在线章节加载流程

```
请求章节内容
   ↓
[检查本地缓存]
   ├→ 有缓存且未过期
   │    ↓
   │    [直接返回缓存]
   │    ↓
   │    [后台验证更新]
   │
   └→ 无缓存或已过期
        ↓
        [发起网络请求]
        ↓
        [书源返回内容]
        ↓
        [内容清洗]
        │  - 移除广告
        │  - 修正格式
        │  - 提取图片
        ↓
        [写入缓存]
        ↓
        [返回内容]
```

### 本地章节加载流程

```
请求本地章节
   ↓
[查询 local_chapter 表]
   ├→ 章节存在
   │    ↓
   │    [读取章节内容]
   │    ↓
   │    [解析格式]
   │    │  - TXT: 纯文本
   │    │  - EPUB: HTML + 图片
   │    │  - PDF: 页面渲染
   │    ↓
   │    [返回内容]
   │
   └→ 章节不存在
        ↓
        [检查索引状态]
        ├→ ready: 异常，报错
        └→ 其他: 提示重新索引
```

### 内容渲染流程

```
接收章节内容
   ↓
[内容类型判断]
   ├→ 纯文本
   │    ↓
   │    [文本分段]
   │    ↓
   │    [应用样式]
   │    ↓
   │    [分页计算]
   │    ↓
   │    [渲染显示]
   │
   ├→ 图文混排
   │    ↓
   │    [解析 HTML]
   │    ↓
   │    [下载图片]
   │    ↓
   │    [图文布局]
   │    ↓
   │    [渲染显示]
   │
   └→ PDF
        ↓
        [页面渲染]
        ↓
        [矢量化处理]
        ↓
        [显示]
```

### 性能优化策略

```
1. 分页预计算
   - 字号变化时重新计算
   - 缓存分页结果
   - 快速跳转

2. 图片懒加载
   - 可见区域优先
   - 预加载相邻页
   - 内存控制

3. 渲染优化
   - RepaintBoundary 隔离
   - 避免全局 rebuild
   - 滚动性能优化
```

## 🔄 状态流转图

### 阅读器状态机

```
[空闲] 
   ↓ 用户打开书籍
[加载中]
   ├→ 加载成功 → [阅读中]
   │                  ↓
   │              各种交互
   │                  ├→ 翻页
   │                  ├→ 调整设置
   │                  ├→ 切换章节
   │                  └→ 关闭 → [空闲]
   │
   └→ 加载失败 → [错误状态]
                     ↓ 重试
                  [加载中]
```

### 章节加载状态

```
[未加载]
   ↓
[加载中]
   ├→ 成功 → [已加载]
   │            ↓
   │         [已渲染]
   │            ↓
   │         [已缓存]
   │
   └→ 失败 → [加载失败]
                ↓ 重试
             [加载中]
```
