# 第一部分：双JSON存储方案（当前任务）

## 🎯 核心思路

**保存两份JSON：**
- `source_json` - 用户原始（完全保真）
- `source_json_normalized` - Rust规整后（100%可用）
- `normalization_warnings` - 兼容性提示

**使用策略：**
- 阅读器用：`normalized`（保证能用）
- 编辑时显示：`original`（保真）+ `warnings`（透明）

# 第三部分：长期标准化战略（1-2年）

## 🎯 标准书源2.0设计

### 核心原则

**保留Legado优点：** ✅
- 规则引擎（JSONPath + JS）
- 分组系统
- 登录系统
- 变量系统

**改进Legado缺点：** ✅
- 扁平结构 → 分层（meta/config/auth/rules）
- String存JSON → 直接对象
- Int魔法值 → 字符串枚举
- 冗长命名 → 简化

---

### 标准2.0结构

```json
{
  "version": "2.0",
  "meta": {
    "name": "书源名称",
    "url": "https://example.com",
    "type": "novel",
    "group": "玄幻"
  },
  "config": {
    "userAgent": "Mozilla...",
    "headers": {"Referer": "..."},
    "timeout": 5000
  },
  "auth": {
    "type": "form",
    "loginUrl": "...",
    "config": {...}
  },
  "rules": {
    "search": {...},
    "detail": {...},
    "toc": {...},
    "content": {...}
  }
}
```
