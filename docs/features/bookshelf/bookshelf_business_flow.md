## 📋 业务流程概览

书架管理核心业务流程分为 **6 个主要流程**：

1. **书架加载流程** - 启动和数据加载
2. **书籍展示流程** - 筛选、排序、分页
3. **分类管理流程** - 创建、编辑、移动
4. **批量操作流程** - 选择、执行、撤销
5. **搜索流程** - 实时搜索、结果展示
6. **书架清理流程** - 智能建议、批量清理

## 🔄 流程 1: 书架加载流程

### 业务流程图

```
App 启动
   ↓
[进入书架页面]
   ↓
[检查书架状态]
```

### 关键步骤说明

#### 步骤 1: 数据加载（并行）
```dart
// 并行加载多个数据源
Future<void> loadBookshelf() async {
  final results = await Future.wait([
    _loadBooks(),           // 书籍列表
    _loadCategories(),      // 分类
    _loadTags(),           // 标签
    _loadReadingProgress(), // 阅读进度
    _loadSettings(),       // 用户设置
  ]);

```

#### 步骤 2: 筛选和排序
```dart
// 应用筛选器
List<BookshelfBook> _applyFilter(
  List<BookshelfBook> books,
  BookshelfFilter filter,
) {
  return switch (filter) {
    BookshelfFilter.all => books,
    BookshelfFilter.reading => books.where((b) => b.isReading),
    BookshelfFilter.finished => books.where((b) => b.isFinished),
    BookshelfFilter.local => books.where((b) => b.isLocal),
    // ...
  };
}

// 应用排序
List<BookshelfBook> _applySort(
  List<BookshelfBook> books,
  BookshelfSortMode sort,
) {
  return switch (sort) {
    BookshelfSortMode.recentRead => books.sortedBy((b) => b.lastReadTime),
    BookshelfSortMode.createdAt => books.sortedBy((b) => b.createdAt),
    BookshelfSortMode.title => books.sortedBy((b) => b.title),
    // ...
  };
}
```

### 虚拟列表优化（大书架）

```
大书架渲染策略:
   ↓
[检测书籍数量]
   ├→ < 50 本
   │    ↓
   │    [普通列表渲染]
   │    └─ 一次性渲染全部
   │
   └→ ≥ 50 本
        ↓
        [虚拟列表渲染]
        ├─ 只渲染可见区域 + 缓冲区
        ├─ 滚动时动态加载
        ├─ 回收不可见项
        └─ 保持滚动性能（60fps）
```

## 🔄 流程 5: 搜索流程

### 实时搜索流程

```
用户输入搜索
   ↓
[点击搜索框]
   ↓
[显示搜索界面]
   ├─ 显示搜索历史
   └─ 显示搜索建议
   ↓
[用户输入关键词]
   ↓
[实时搜索（防抖 300ms）]
   ↓
[并行搜索多个字段]
   ├─ 书名匹配
   ├─ 作者匹配
   ├─ 拼音匹配
   └─ 分类标签匹配
   ↓
[计算匹配度排序]
   ├─ 完全匹配（100分）
   ├─ 前缀匹配（80分）
   ├─ 包含匹配（60分）
   └─ 拼音匹配（40分）
   ↓
[显示搜索结果]
   ├─ 高亮关键词
   ├─ 按匹配度排序
   └─ 显示匹配字段
   ↓
[点击结果]
   ├─ 保存到搜索历史
   └─ 跳转到对应书籍
```

### 搜索性能优化

```
搜索优化策略:

1. 防抖（Debounce）
   - 用户输入后 300ms 才触发搜索
   - 避免频繁搜索

2. 索引优化
   - 预建立书名、作者索引
   - 拼音索引（首字母）
   - 使用 Trie 树或倒排索引

3. 分页加载
   - 首屏只显示 20 条结果
   - 滚动加载更多

4. 缓存结果
   - 缓存最近搜索结果
   - 相同关键词直接返回
```
