# 我的书源 UI 设计规范

更新时间：2026-06-10  
适用范围：Android、iOS、Web、macOS、Windows、Linux

## 1. 设计目标

为"我的书源"功能设计符合 Selune 品牌气质的多平台 UI，在保持移动端体验稳定的前提下，为桌面端和 Web 端提供符合各自平台习惯的交互方式。

## 2. 核心设计原则

- 移动端优先，保持现有稳定体验
- 桌面端适配大屏，提升信息密度和操作效率
- 遵循 Selune 品牌规范：轻、静、柔、精
- 使用项目统一的 UI Token 和 Adaptive 组件
- 响应式布局，适配 320px ~ 2560px 宽度

## 3. 平台断点定义

根据 `AppAdaptiveMetrics` 定义：

- **Mobile/Compact**：`< 600dp`
- **Narrow Desktop**：`600 - 839dp`
- **Medium Desktop**：`840 - 1279dp`
- **Wide Desktop**：`≥ 1280dp`

## 4. 页面结构设计

### 4.1 移动端布局（< 600dp）

#### 顶栏
- 固定顶栏，带毛玻璃背景
- 标题："我的书源"
- 副标题："私人书源与共享审核"（可选，空间充足时显示）
- 右侧操作：分组按钮 + 新增按钮

#### 工具栏
- 搜索框：占满宽度，带清除按钮
- 分组选择器：下拉菜单，显示当前选中分组

#### 配额卡片
- 横向两列布局
- 左侧：总书源配额
- 右侧：每日检测配额
- 使用低对比度胶囊样式

#### 书源列表
- 垂直列表，单列显示
- 卡片样式，圆角 16dp
- 点击卡片进入编辑
- 右上角更多按钮展开操作菜单

#### 空状态
- 居中图标 + 文案
- 主按钮：新增书源

### 4.2 窄桌面布局（600 - 839dp）

#### 整体结构
- 保持移动端垂直布局
- 增加左右内边距（24 - 32dp）
- 最大内容宽度：720dp

#### 工具栏优化
- 搜索框和分组选择器横向排列
- 搜索框占 60% 宽度
- 分组选择器占 40% 宽度

#### 书源列表
- 仍然单列显示
- 卡片内增加更多信息展示
- 操作按钮可以部分外显

### 4.3 中等桌面布局（840 - 1279dp）

#### 整体结构
- 内容居中，最大宽度 960dp
- 顶栏操作按钮可以展开为文字按钮

#### 工具栏
- 搜索框占据更大空间
- 分组选择器宽度固定（180 - 200dp）
- 可以添加快捷筛选选项

#### 书源列表
- 考虑双列布局（可选）
- 卡片宽度自适应
- 列间距 16dp

#### 操作优化
- 悬停显示更多信息
- 可以显示内联操作按钮
- 支持右键菜单

### 4.4 宽桌面布局（≥ 1280dp）

#### 整体结构
- 内容最大宽度 1200dp
- 可选：侧边栏 + 主内容区域布局

#### 侧边栏（可选）
- 左侧固定宽度 240 - 280dp
- 显示分组列表
- 支持拖拽排序
- 底部显示配额信息

#### 主内容区域
- 顶部工具栏：搜索 + 操作按钮
- 列表支持双列或三列布局
- 可选：表格视图模式

#### 高级功能
- 批量选择模式
- 拖拽排序
- 分组拖拽移动
- 键盘快捷键支持

## 5. 组件设计规范

### 5.1 书源卡片

#### 移动端卡片（< 600dp）
```
┌─────────────────────────────────────┐
│ [名称]                      [更多▼] │
│ 类型 · 分组 · 状态 · 检测结果      │
└─────────────────────────────────────┘
```

尺寸：
- 高度：72dp
- 圆角：16dp
- 内边距：12dp（左右）、9dp（上下）
- 边框：1dp，颜色 `outlineVariant.withAlpha(0.32)`
- 背景：`surfaceContainerLow.withAlpha(0.82)`

内容层级：
- 第一行：名称（标题样式，fontWeight: 800） + 更多按钮
- 第二行：元信息（小字体，onSurfaceVariant）

#### 桌面端卡片（≥ 600dp）
```
┌──────────────────────────────────────────┐
│ [名称]                    [检测] [编辑]  │
│ 类型 · 分组 · 审核状态                  │
│ 检测：通过 · 描述信息...                │
└──────────────────────────────────────────┘
```

尺寸：
- 高度：auto（根据内容）
- 最小高度：86dp
- 可以显示更多信息行

交互增强：
- 悬停高亮
- 操作按钮外显
- 支持右键菜单

### 5.2 搜索框

#### 样式
- 高度：40dp
- 圆角：14dp
- 背景：`surfaceContainerLowest.withAlpha(0.92)`
- 边框：`outlineVariant.withAlpha(0.28)`
- 提示文字："搜索书源名称、分组、描述"

#### 交互
- 输入时实时过滤
- 显示清除按钮
- 支持键盘快捷键（Cmd/Ctrl + F）

### 5.3 分组选择器

#### 移动端
- 下拉菜单按钮
- 高度：40dp
- 圆角：14dp
- 显示当前分组名称
- 点击弹出底部抽屉

#### 桌面端
- 下拉菜单按钮
- 悬停显示提示
- 点击弹出对话框选择器
- 支持快捷键切换

### 5.4 配额展示

#### 样式
- 胶囊形状，圆角 999dp
- 背景：`surfaceContainerHighest.withAlpha(0.58)`
- 边框：`outlineVariant.withAlpha(0.52)`
- 内边距：10dp（左右）、7dp（上下）

#### 布局
- 移动端：横向两列，均分宽度
- 桌面端：可以排列在一行，或放在侧边栏

### 5.5 操作按钮

#### 主要操作按钮
- 新增书源：`FilledButton`，primary 色
- 检测：`OutlinedButton` 或 `TextButton`
- 编辑：`TextButton` 或内联图标按钮

#### 危险操作
- 删除：error 色
- 在确认对话框中使用 `FilledButton` + error 色

### 5.6 表单设计

#### 书源编辑表单
- 移动端：全屏底部抽屉
- 桌面端：居中对话框，最大宽度 680dp

字段：
- 名称：单行文本框
- 类型：下拉选择器（小说、漫画、音频、视频）
- 分组：自动完成输入框
- 描述：多行文本框（2-4行）
- 书源JSON：代码编辑器（8-14行）

操作：
- 底部固定：取消 + 保存按钮

#### 分组管理
- 移动端：底部抽屉
- 桌面端：对话框，最大宽度 560dp

布局：
- 顶部：新增分组输入框 + 新增按钮
- 下方：分组列表
- 每项：名称 + 重命名按钮 + 删除按钮

## 6. 响应式适配策略

### 6.1 布局切换

| 宽度范围 | 列数 | 卡片宽度 | 内边距 |
|---------|------|---------|--------|
| < 600dp | 1列 | 100% | 16-20dp |
| 600-839dp | 1列 | 100% | 24-32dp |
| 840-1279dp | 2列 | ~48% | 32-40dp |
| ≥ 1280dp | 2-3列 | ~32% | 40-48dp |

### 6.2 操作优化

| 平台 | 主要操作 | 次要操作 | 更多菜单 |
|------|---------|---------|---------|
| 移动端 | 顶栏图标按钮 | 卡片更多菜单 | PopupMenu |
| 窄桌面 | 顶栏文字按钮 | 卡片更多菜单 | PopupMenu |
| 宽桌面 | 顶栏文字按钮 | 卡片内联按钮 | 右键菜单 |

### 6.3 信息密度

- 移动端：精简信息，只显示关键字段
- 窄桌面：增加一行元信息
- 宽桌面：显示完整信息，增加悬停提示

## 7. 交互设计

### 7.1 手势和操作

#### 移动端
- 点击卡片：进入编辑
- 点击更多按钮：展开操作菜单
- 下拉刷新：刷新列表
- 长按：未来可支持批量选择

#### 桌面端
- 单击卡片：进入编辑
- 双击卡片：快速操作（可选）
- 右键卡片：显示上下文菜单
- 悬停：高亮显示，展示更多信息
- 拖拽：未来支持排序和分组移动

### 7.2 键盘快捷键（桌面端）

- `Cmd/Ctrl + N`：新增书源
- `Cmd/Ctrl + F`：聚焦搜索
- `Cmd/Ctrl + G`：打开分组管理
- `Cmd/Ctrl + R`：刷新列表
- `Esc`：关闭对话框/清空搜索
- `↑/↓`：导航列表
- `Enter`：确认操作

### 7.3 状态反馈

#### 加载状态
- 首次加载：骨架屏或加载卡片
- 刷新：顶部进度条
- 操作中：按钮显示"保存中"等文字

#### 空状态
- 无书源：插图 + 文案 + 新增按钮
- 搜索无结果：提示清空搜索
- 网络错误：错误图标 + 重试按钮

#### 成功反馈
- 轻量级 SnackBar 提示
- 自动消失（3-5秒）
- 位置：底部居中

## 8. 动画和过渡

### 8.1 页面切换
- 移动端：标准 Material 页面过渡
- 桌面端：淡入淡出，持续 200ms

### 8.2 对话框
- 移动端：底部抽屉滑入，带背景遮罩
- 桌面端：居中淡入 + 轻微缩放

### 8.3 列表项
- 新增：淡入 + 从上滑入
- 删除：淡出 + 向左滑出
- 更新：轻微闪烁高亮

### 8.4 交互反馈
- 按钮点击：水波纹效果
- 卡片悬停：轻微阴影提升
- 拖拽：透明度降低 + 阴影增强

## 9. 暗色模式适配

### 9.1 颜色调整
- 使用 Theme 的 `colorScheme`
- 自动适配浅色和暗色模式
- 不硬编码固定颜色

### 9.2 对比度
- 暗色模式下增加边框可见度
- 卡片背景使用 `surfaceContainer` 层级
- 文字保持足够对比度

## 10. 无障碍设计

### 10.1 语义化
- 所有交互元素添加 `Semantics`
- 按钮提供清晰的 `tooltip`
- 表单字段提供 `labelText`

### 10.2 对比度
- 文字与背景对比度 ≥ 4.5:1
- 图标与背景对比度 ≥ 3:1
- 状态颜色不只依赖颜色区分

### 10.3 操作反馈
- 触摸目标最小 44x44dp
- 提供清晰的聚焦指示
- 支持键盘导航

## 11. 实现建议

### 11.1 保持移动端稳定
- 现有移动端页面保持不变
- 新增桌面适配代码使用条件判断
- 通过 `AppAdaptiveMetrics` 判断断点

### 11.2 使用现有组件
- `AdaptiveOverflowToolbar`：顶栏操作
- `AdaptiveListTile`：列表项
- `showAdaptiveActionSurface`：对话框/抽屉
- `AppAdaptiveMetrics`：断点判断

### 11.3 渐进式增强
- 第一阶段：优化窄桌面布局（600-839dp）
- 第二阶段：实现中等桌面双列布局（840-1279dp）
- 第三阶段：宽桌面侧边栏和高级功能（≥ 1280dp）

### 11.4 测试覆盖
- 移动端：320px、360px、390px、428px
- 平板：768px、834px、1024px
- 桌面：1280px、1440px、1920px、2560px
- 各平台真机/模拟器验证

## 14. 验收标准

### 14.1 功能完整性
- ✓ 所有现有功能在各平台正常工作
- ✓ 移动端体验无回退
- ✓ 桌面端操作效率提升
- ✓ 响应式布局在所有断点正常

### 14.2 视觉一致性
- ✓ 符合 Selune 品牌规范
- ✓ 使用统一 UI Token
- ✓ 暗色模式正确适配
- ✓ 图标和文案统一

### 14.3 性能标准
- ✓ 首屏渲染 < 300ms
- ✓ 搜索响应 < 100ms
- ✓ 对话框动画流畅 ≥ 60fps
- ✓ 大列表滚动流畅

### 14.4 无障碍达标
- ✓ 屏幕阅读器支持
- ✓ 键盘导航完整
- ✓ 对比度符合 WCAG AA
- ✓ 触摸目标尺寸达标
