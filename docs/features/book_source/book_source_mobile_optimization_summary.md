更新时间：2026-06-10  
优化范围：Android、iOS 移动端

## 1. 优化概述

本次优化对"我的书源"页面进行了移动端视觉细节调整，确保完全符合 Selune 品牌设计规范，同时保持现有功能稳定性。

- ✅ 简化布局结构：移除不必要的 Row 嵌套

- ✓ 背景色使用正确的 token
