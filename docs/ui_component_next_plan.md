# UI 组件后续推进计划（精简版）

## P0（先做，直接影响可用性）

1. 阅读器：背景图上传后增加压缩与尺寸约束，防止内存抖动。
2. 阅读器：翻页效果增加轻量预览条，避免用户盲选。
3. 阅读器：目录弹层视觉统一（当前章高亮、分组定位、滚动定位按钮常驻）。
4. 搜索页：结果卡片增加“在读/已在书架”状态标识，减少重复操作。
5. 详情页：目录区域支持按关键字过滤章节（长篇小说必备）。
6. 书架页：网格模式支持长按多选（删除/批量标记已读）。

## P1（增强体验）

1. 书源页：卡片三点菜单增加“复制规则请求”和“快速禁用 24h”。
2. 我的页：加入阅读统计卡（连续阅读天数、当日阅读时长、本周进度）。
3. 搜索页：失败书源明细支持“重试失败源”而非全量重搜。
4. 详情页：最新章节与目录支持“更新提醒”占位交互。
5. 阅读器：工具栏动画统一为同一节奏（出现/隐藏 180ms）。

## P2（收尾与发布前）

1. 全局动效审查：统一曲线、时长、触控反馈。
2. 字体体系统一：标题/正文/辅助文字层级和字重基线固化。
3. 多端适配：Android、iOS、macOS、Windows 四端最小验收走查。
4. 无障碍：基础语义标签与最小触控区域优化。

## 建议执行顺序

- 第 1 周：P0 的 1~4。
- 第 2 周：P0 的 5~6 + P1 的 1~2。
- 第 3 周：P1 的 3~5 + P2 全量走查。
