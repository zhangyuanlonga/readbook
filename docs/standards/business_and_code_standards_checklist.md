## 2. 代码标准与架构

### 2.1 架构分层 

- [ ] **核心问题：是否所有模块都遵循分层架构？**
  - Presentation 层只负责UI
  - Application 层负责业务逻辑
  - Data 层负责数据访问
  - 检查：`dart tool/check_architecture_guardrails.dart`

- [ ] **跨层依赖检查**
  - core 不能依赖 features
  - presentation 不能直接访问 data
  - 使用 Provider/Service 注入依赖

### 2.2 状态管理统一

- [ ] **是否使用统一的状态管理？**
  - 当前：Riverpod
  - 检查：是否有混用 Provider、setState、全局变量
  - 规范：新代码必须使用 Riverpod

- [ ] **状态生命周期管理**
  - 页面销毁时是否正确清理状态
  - 是否有内存泄漏
  - 使用 autoDispose 自动清理

### 2.3 错误处理统一

- [ ] **API错误处理是否统一？**
  - 网络错误、超时、401、403、500 等
  - 是否有统一的错误提示
  - 是否记录错误日志

- [ ] **异常捕获是否完整？**
  - 异步操作是否都有 try-catch
  - 是否有全局异常捕获
  - 文件：`lib/core/errors/`

## 3. 平台一致性

### 3.1 多平台行为一致

- [ ] **核心功能是否在所有平台一致？**
  - Android / iOS / Web / Desktop
  - 登录登出流程
  - 数据存储和读取
  - API请求行为

- [ ] **平台差异是否正确隔离？**
  - 使用条件导入：`_io.dart` / `_web.dart`
  - 使用 Platform Adapter 模式
  - 不在业务层直接判断平台

### 3.2 响应式适配

- [ ] **UI是否适配不同屏幕？**
  - 移动端：< 600dp
  - 平板/窄桌面：600-839dp
  - 桌面：≥ 840dp
  - 使用 `AppAdaptiveMetrics` 判断

## 4. 数据安全

### 4.1 敏感信息保护

- [ ] **敏感信息是否加密存储？**
  - Token、密码使用 SecureStorage
  - 不在 SharedPreferences 存储敏感信息
  - 不在日志中输出敏感信息

- [ ] **日志脱敏**
  - API请求不记录完整token
  - 不记录用户密码
  - 不记录完整文件路径

### 4.2 权限控制

- [ ] **文件访问权限**
  - 用户资产文件权限正确
  - 临时文件及时清理
  - 不随意访问系统目录

- [ ] **网络请求安全**
  - HTTPS请求
  - 证书校验（生产环境）
  - 防止中间人攻击

## 5. 性能优化

### 5.1 启动性能

- [ ] **首屏渲染是否够快？**
  - 目标：< 500ms
  - 避免启动时同步加载大数据
  - 使用懒加载

- [ ] **启动任务是否合理？**
  - 必要任务同步执行
  - 非必要任务延迟执行
  - 使用 `StartupTaskGateService` 控制频率

### 5.2 列表性能

- [ ] **长列表是否优化？**
  - 使用 ListView.builder
  - 图片懒加载
  - 避免重建整个列表

- [ ] **缓存是否合理？**
  - 图片缓存大小限制
  - 数据缓存过期清理
  - 避免无限增长

### 5.3 内存管理

- [ ] **是否有内存泄漏？**
  - StreamSubscription 是否正确取消
  - Controller 是否正确 dispose
  - 使用 autoDispose Provider

## 9. 遗漏风险点识别

### 9.1 当前已识别问题 ✅

1. ✅ 用户状态混乱（已规划）
2. ✅ API缓存不当（已规划）
3. ✅ 数据清理不完整（已规划）
4. ✅ 覆盖安装问题（已规划）

### 9.2 潜在风险点 ⚠️

1. **并发请求冲突**
   - 多个请求同时修改同一数据
   - 需要：请求队列或锁机制

2. **离线模式处理**
   - 断网时的降级策略
   - 离线数据与在线数据同步

3. **大文件处理**
   - 本地图书导入（大文件）
   - 是否有进度提示
   - 是否可取消

4. **通知和推送**
   - 消息推送是否与用户绑定
   - 登出后是否停止推送

5. **第三方SDK**
   - 是否正确初始化
   - 是否处理异常
   - 是否及时清理

6. **WebView 安全**
   - 是否限制跳转
   - 是否注入JS
   - Cookie 是否隔离
