## 九、设计审查清单

每次新增或修改 UI 时，使用此清单自查：

### 视觉设计

- [ ] 是否使用了 Design Token？
- [ ] 圆角是否符合规范？
- [ ] 间距是否符合规范？
- [ ] 颜色是否使用了 ColorScheme？
- [ ] 是否有视觉层次？

### 交互设计

- [ ] 是否有点击反馈？
- [ ] 是否有加载状态？
- [ ] 是否有空状态？
- [ ] 是否有错误状态？
- [ ] 危险操作是否有确认？

### 动画设计

- [ ] 动画时长是否符合规范？
- [ ] 动画曲线是否符合规范？
- [ ] 动画是否流畅（60fps）？
- [ ] 动画是否有意义？
- [ ] 是否考虑了性能？

### 响应式设计

- [ ] 是否适配移动端？
- [ ] 是否适配平板？
- [ ] 是否适配桌面端？
- [ ] 触摸目标是否足够大？
- [ ] 鼠标交互是否完善？

### 无障碍

- [ ] 颜色对比度是否达标？
- [ ] 触摸目标是否≥44x44dp？
- [ ] 是否有语义化标签？
- [ ] 是否支持键盘导航？
